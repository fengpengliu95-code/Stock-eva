# 股票估值方法 — 如何判断一只股票贵不贵

> **核心问题**：一只股票的市场价格是 100 元，它到底是"贵"了还是"便宜"了？
> 估值，就是回答这个问题的工具箱。

---

## 一、为什么要做估值？

### 1.1 价格 vs 价值：最核心的区别

| 概念 | 含义 | 决定因素 | 特征 |
|------|------|----------|------|
| **价格（Price）** | 市场上买卖双方成交的金额 | 供需关系、情绪、资金流向 | 短期波动剧烈，受情绪驱动 |
| **价值（Value）** | 企业未来创造现金流的折现总和 | 盈利能力、成长性、护城河 | 长期相对稳定，由基本面决定 |

> **沃伦·巴菲特**："价格是你付出的，价值是你得到的。"（Price is what you pay, value is what you get.）

**核心逻辑**：短期来看，价格可能偏离价值（被高估或低估），但长期来看，价格终将回归价值。估值的目的，就是**找到价格与价值之间的差距**，从而做出投资决策。

### 1.2 市场先生的寓言

本杰明·格雷厄姆在《聪明的投资者》中讲了一个经典故事：

> 想象你拥有一家价值 100 万的企业的一小部分股份。你有一个合伙人叫"**市场先生**"（Mr. Market），他每天都会报一个价格，愿意买你的股份或卖给你更多股份。
>
> 但市场先生有个特点：**他情绪极不稳定**。有时他乐观过头，报出一个远高于企业价值的价格；有时他恐慌沮丧，报出一个远低于企业价值的价格。
>
> 你的优势在于：**你可以选择忽略他**。只在他报出的价格对你有利时，才与他交易。

**启示**：股市中，"市场先生"就是每天跳动的股价。不要被他的情绪左右，而是用估值来判断价格是否合理。

### 1.3 安全边际（Margin of Safety）

安全边际是格雷厄姆提出的核心投资概念：

**安全边际 = 内在价值 - 市场价格**

- 如果一只股票的内在价值是 **50 元**，当前股价是 **35 元**，那么安全边际 = 15 元（30%）。
- 安全边际越大，投资风险越低，潜在收益越高。

**经验法则**：
- 安全边际 > **30%**：具有较好的投资吸引力
- 安全边际 > **50%**：极具投资价值（但需确认不是"价值陷阱"）
- 安全边际 < **0%**（即价格 > 价值）：可能被高估，谨慎买入

> [!TIP]
> 估值永远是一个**区间**，而非一个精确数值。不要追求"精确的错误"，而要追求"模糊的正确"。

## 二、相对估值法

相对估值法的核心思想：**通过对比，判断一只股票相对于同行、相对于历史是贵还是便宜。**

### 2.1 PE（市盈率）— 最常用的估值指标

#### 2.1.1 公式

**PE = [股价 / 每股收益(EPS)] = [总市值 / 净利润]**

**含义**：假设企业当前的盈利能力保持不变，投资者需要多少年才能通过利润收回投资成本。

- PE = 20 → 需要 20 年回本（假设利润不变）
- PE = 10 → 需要 10 年回本

#### 2.1.2 三种 PE 的区别

| PE 类型 | 计算方式 | 优点 | 缺点 |
|---------|----------|------|------|
| **静态 PE** | 总市值 ÷ 上年度净利润 | 数据确定 | 滞后性强，可能已过时 |
| **TTM PE（滚动市盈率）** | 总市值 ÷ 最近 4 个季度净利润之和 | 较为及时 | 可能包含非经常性损益 |
| **动态 PE** | 总市值 ÷ 预测当年净利润 | 前瞻性强 | 依赖预测，可能不准确 |

> [!IMPORTANT]
> 实际投资中，**TTM PE** 使用最为广泛。看研报或行情软件时，默认显示的通常也是 TTM PE。

#### 2.1.3 计算示例：贵州茅台

假设贵州茅台（600519）的数据如下：

| 指标 | 数值 |
|------|------|
| 当前股价 | 1,580 元 |
| 总股本 | 12.56 亿股 |
| 总市值 | 1,580 × 12.56 亿 ≈ **19,845 亿元** |
| 最近四个季度净利润（TTM） | **747 亿元** |

**PE_(TTM) = [19,845亿 / 747亿] ≈ 26.6倍**

**解读**：按当前盈利水平，投资者约需 26.6 年通过利润回本。对于消费行业龙头而言，这一估值处于**合理偏低**区间。

#### 2.1.4 不同行业的合理 PE 区间

| 行业 | 合理 PE 区间 | 代表公司 | 说明 |
|------|-------------|----------|------|
| **银行** | 5 - 8x | 招商银行、工商银行 | 利润稳定但增长慢，受坏账影响大 |
| **保险** | 8 - 15x | 中国平安、中国人寿 | 长周期业务，利润波动较大 |
| **地产** | 5 - 10x | 万科A、保利发展 | 周期性强，政策影响大 |
| **白酒/消费** | 20 - 35x | 贵州茅台、五粮液 | 品牌护城河深，现金流优秀 |
| **医药** | 25 - 40x | 恒瑞医药、药明康德 | 研发驱动，高增长预期 |
| **科技/半导体** | 30 - 60x | 宁德时代、中芯国际 | 高增长预期，但利润波动大 |
| **新能源车** | 40 - 80x | 比亚迪、理想汽车 | 处于高速增长期，市场给予溢价 |
| **互联网** | 20 - 40x | 腾讯控股、美团 | 平台效应强，但监管风险存在 |
| **公用事业** | 10 - 18x | 长江电力、中国核电 | 稳定性极强，类债券资产 |
| **周期行业** | 不适用固定区间 | 紫金矿业、中国神华 | 盈利随周期波动，PE反而在高点时低 |

> [!WARNING]
> **周期股的 PE 陷阱**：周期行业在景气高点时利润暴增，PE 看起来很"便宜"（如 5 倍），但此时反而可能是卖出时机；在景气低点时利润大幅下滑甚至亏损，PE 很高或为负值，反而可能是买入时机。这与一般逻辑完全**相反**！

#### 2.1.5 PE 的局限性

1. **不适用于亏损企业**：净利润为负时，PE 无意义
2. **容易被利润调节误导**：一次性收益（卖资产、政府补贴）可能扭曲 PE
3. **不考虑负债水平**：高杠杆企业的 PE 可能被低估
4. **不同会计准则下不可直接比较**：A 股与港股的会计处理可能有差异
5. **忽视增长速度**：同样 30 倍 PE，增速 50% 和增速 5% 的公司差异巨大

### 2.2 PB（市净率）— 重资产行业的核心指标

#### 2.2.1 公式

**PB = [股价 / 每股净资产] = [总市值 / 净资产(股东权益)]**

**含义**：投资者为每 1 元的净资产支付了多少钱。

- PB = 1 → 按净资产原价买入（"平价"）
- PB < 1 → 低于净资产买入（"破净"）
- PB > 3 → 大幅高于净资产，说明市场认可其无形资产或增长潜力

#### 2.2.2 适用场景

PB 最适合用于**资产驱动型**企业：

| 行业 | PB 的适用性 | 合理 PB 区间 | 原因 |
|------|------------|-------------|------|
| 银行 | ⭐⭐⭐⭐⭐ | 0.5 - 1.2x | 资产（贷款）可较准确衡量 |
| 地产 | ⭐⭐⭐⭐ | 0.6 - 1.5x | 土地储备是核心资产 |
| 钢铁/建材 | ⭐⭐⭐⭐ | 0.8 - 1.5x | 重资产行业，厂房设备为主 |
| 科技 | ⭐ | 不适用 | 核心价值在于人才和技术，账面资产少 |
| 消费品牌 | ⭐⭐ | 仅参考 | 品牌价值不体现在净资产中 |

#### 2.2.3 计算示例：招商银行

假设招商银行（600036）的数据如下：

| 指标 | 数值 |
|------|------|
| 当前股价 | 38 元 |
| 每股净资产 | 38.5 元 |

**PB = [38 / 38.5] ≈ 0.99倍**

**解读**：PB 接近 1 倍，说明市场对招商银行的估值基本等于其账面净资产。对于银行业龙头，这一水平属于**合理偏低**。

#### 2.2.4 破净股分析

"破净"即 PB < 1，意味着股价低于每股净资产。

**破净可能的原因**：
1. **市场整体低迷**，优质股被错杀（机会）
2. **资产质量存疑**，如银行坏账率高、地产存货减值（陷阱）
3. **盈利能力差**，ROE 长期低于资本成本（价值毁灭）
4. **行业处于衰退期**，资产未来可能进一步贬值

> [!CAUTION]
> 破净 ≠ 便宜！需要结合 **ROE（净资产收益率）** 综合判断。如果 ROE < 资本成本（通常 8%-10%），则企业在**毁灭股东价值**，破净是合理的。

**判断公式**：

**合理PB ≈ [ROE / 资本成本] = [ROE / WACC]**

如果 ROE = 15%，WACC = 10%，则合理 PB = 1.5 倍。

### 2.3 PS（市销率）— 亏损企业的估值利器

#### 2.3.1 公式

**PS = [总市值 / 年营业收入] = [股价 / 每股营收]**

**含义**：投资者为企业每 1 元的营业收入支付了多少钱。

#### 2.3.2 适用场景

PS 最适合以下类型的企业：

1. **尚未盈利的互联网/科技企业**：PE 无法使用时，PS 是替代方案
2. **高增长初创期企业**：收入快速增长但仍在亏损
3. **SaaS / 平台型企业**：如早期的美团、拼多多

#### 2.3.3 计算示例

假设某新能源初创企业：
- 总市值：500 亿元
- 年营业收入：100 亿元

**PS = [500亿 / 100亿] = 5倍**

**行业参考**：
| PS 范围 | 含义 |
|---------|------|
| PS < 1 | 可能被低估，或行业利润率极低 |
| PS = 1-3 | 传统行业合理范围 |
| PS = 3-10 | 高增长行业可接受 |
| PS > 10 | 通常意味着市场对未来增长有极高预期 |

> [!NOTE]
> PS 的最大缺陷是**完全忽视了利润率**。一家 PS = 2 但净利率仅 1% 的企业，隐含 PE = 200 倍！因此，使用 PS 时必须结合毛利率和净利率趋势分析。

---

### 2.4 PEG — 彼得·林奇的核心估值指标

#### 2.4.1 公式

**PEG = [PE / 净利润增长率(%)]**

> **注意**：增长率使用百分比的数值部分，例如增长率 25% 则取 25，而非 0.25。

#### 2.4.2 判断标准

| PEG 范围 | 含义 | 投资建议 |
|----------|------|----------|
| PEG < 0.5 | 严重低估 | 积极买入（需确认增长可持续） |
| PEG = 0.5-1.0 | 合理偏低 | 可以考虑买入 |
| PEG = 1.0 | 合理估值 | 增长与估值匹配 |
| PEG = 1.0-1.5 | 合理偏高 | 谨慎持有 |
| PEG > 2.0 | 明显高估 | 考虑卖出 |

#### 2.4.3 计算示例：宁德时代

假设宁德时代（300750）的数据如下：

| 指标 | 数值 |
|------|------|
| 当前 PE（TTM） | 25 倍 |
| 预计未来 3 年净利润复合增长率 | 30% |

**PEG = [25 / 30] ≈ 0.83**

**解读**：PEG < 1，说明宁德时代的估值**低于其增长速度**，具有较好的投资价值（前提是 30% 的增长率能够持续兑现）。

#### 2.4.4 PEG 的局限性

1. **依赖增长预测**：未来增长率本身就是不确定的
2. **不适用于周期股**：周期性行业的增长率波动巨大
3. **不适用于低增长企业**：增长率接近 0 时，PEG 趋向无穷大
4. **忽视增长质量**：靠并购增长 vs 靠内生增长，质量完全不同

---

### 2.5 EV/EBITDA — 排除资本结构差异的估值指标

#### 2.5.1 核心概念

**EV（企业价值） = 总市值 + 有息负债 - 现金及现金等价物**

**EBITDA = 息税折旧摊销前利润 = 净利润 + 所得税 + 利息 + 折旧 + 摊销**

**[EV / EBITDA] = [企业价值 / 息税折旧摊销前利润]**

#### 2.5.2 为什么要用 EV/EBITDA？

| 相比 PE 的优势 | 说明 |
|---------------|------|
| 消除资本结构影响 | 不受负债水平高低的影响，适合跨企业比较 |
| 消除税率差异 | 不同国家/地区税率不同时仍可对比 |
| 减少折旧政策影响 | 不同折旧方法不影响 EBITDA |
| 更接近现金流 | EBITDA 是经营现金流的近似值 |

#### 2.5.3 计算示例：比亚迪

假设比亚迪（002594）的数据如下：

| 指标 | 数值 |
|------|------|
| 总市值 | 8,500 亿元 |
| 有息负债 | 1,200 亿元 |
| 现金及等价物 | 800 亿元 |
| EBITDA | 900 亿元 |

**EV = 8,500 + 1,200 - 800 = 8,900亿元**

**[EV / EBITDA] = [8,900 / 900] ≈ 9.9倍**

**行业参考**：

| 行业 | EV/EBITDA 合理区间 |
|------|-------------------|
| 制造业 | 6 - 10x |
| 消费品 | 10 - 18x |
| 科技 | 15 - 30x |
| 公用事业 | 5 - 8x |
| 能源 | 4 - 8x |

## 三、绝对估值法

绝对估值法的核心思想：**企业的价值等于其未来所有现金流的折现值之和。**

### 3.1 DCF（自由现金流折现模型）— 估值的"终极武器"

#### 3.1.1 核心公式

**V = ∑_(t=1)^(n) [FCF_t / (1+WACC)^t] + [TV / (1+WACC)^n]**

其中：
- V = 企业内在价值
- FCF_t = 第 t 年的自由现金流
- WACC = 加权平均资本成本（折现率）
- TV = 终值（Terminal Value）
- n = 预测期年数（通常 5-10 年）

#### 3.1.2 关键概念详解

**① 自由现金流（FCF）**

**FCF = 经营现金流 - 资本支出**

**= EBIT × (1 - 税率) + 折旧摊销 - 资本支出 - 营运资本增加**

自由现金流代表企业在满足所有经营和再投资需求后，**可以自由分配给股东和债权人的现金**。

**② WACC（加权平均资本成本）**

**WACC = [E / E+D] × R_e + [D / E+D] × R_d × (1 - T)**

其中：
- E = 股权市值，D = 有息负债
- R_e = 股权资本成本（可用 CAPM 模型计算：R_e = R_f + β × (R_m - R_f)）
- R_d = 债务资本成本（借贷利率）
- T = 企业所得税率

**A 股常用参数参考**：

| 参数 | 数值 | 说明 |
|------|------|------|
| 无风险利率 R_f | 2.5% - 3.0% | 参考 10 年期国债收益率 |
| 市场风险溢价 R_m - R_f | 5% - 7% | A 股历史风险溢价 |
| 企业所得税率 T | 25%（一般）/ 15%（高新技术） | 参考企业实际税率 |

**③ 终值（Terminal Value）**

预测期之后，假设企业以稳定增长率永续增长：

**TV = [FCF_(n+1) / (WACC - g)] = [FCF_n × (1+g) / (WACC - g)]**

其中 g 为永续增长率，通常取 **2% - 3%**（不超过 GDP 长期增长率）。

> [!WARNING]
> 终值通常占 DCF 估值结果的 **60%-80%**！这意味着永续增长率 g 的微小变化会导致估值结果的巨大波动。因此，DCF 模型**对假设非常敏感**，必须进行敏感性分析。

#### 3.1.3 DCF 估值五步法

**第一步：预测未来 5 年自由现金流**

以贵州茅台为例（简化数据）：

| 年份 | 第1年 | 第2年 | 第3年 | 第4年 | 第5年 |
|------|-------|-------|-------|-------|-------|
| 营业收入（亿元） | 1,650 | 1,880 | 2,120 | 2,360 | 2,600 |
| 增长率 | 14% | 14% | 13% | 11% | 10% |
| FCF（亿元） | 650 | 750 | 860 | 960 | 1,060 |

**第二步：确定 WACC**

假设贵州茅台：
- 几乎零有息负债，因此 WACC ≈ R_e
- R_f = 2.8%，β = 0.8，R_m - R_f = 6%

**R_e = 2.8% + 0.8 × 6% = 7.6%**

**WACC ≈ 7.6%**

**第三步：折现未来现金流**

| 年份 | FCF（亿元） | 折现因子 [1 / (1.076)^t] | 折现值（亿元） |
|------|------------|-------------------------------|--------------|
| 第1年 | 650 | 0.929 | 604 |
| 第2年 | 750 | 0.864 | 648 |
| 第3年 | 860 | 0.803 | 690 |
| 第4年 | 960 | 0.746 | 716 |
| 第5年 | 1,060 | 0.693 | 735 |
| **合计** | | | **3,393** |

**第四步：计算终值并折现**

假设永续增长率 g = 3%：

**TV = [1,060 × (1 + 3%) / 7.6% - 3%] = [1,091.8 / 4.6%] ≈ 23,735亿元**

**TV_(折现) = [23,735 / (1.076)^5] = 23,735 × 0.693 ≈ 16,438亿元**

**第五步：得出企业价值和每股价值**

**企业价值 = 3,393 + 16,438 = 19,831亿元**

**每股价值 = [19,831亿 / 12.56亿股] ≈ 1,579元**

> 这与当前股价 1,580 元基本一致，说明市场对茅台的估值较为合理。

#### 3.1.4 敏感性分析

DCF 估值结果对 WACC 和永续增长率 g 极为敏感。以下是不同假设下的每股估值：

| WACC ↓ / g → | **2.0%** | **2.5%** | **3.0%** | **3.5%** | **4.0%** |
|-------------|---------|---------|---------|---------|---------|
| **6.6%** | 1,750 | 1,920 | 2,130 | 2,400 | 2,780 |
| **7.1%** | 1,520 | 1,650 | 1,800 | 2,000 | 2,260 |
| **7.6%** | 1,340 | 1,440 | **1,579** | 1,730 | 1,920 |
| **8.1%** | 1,190 | 1,280 | 1,380 | 1,500 | 1,650 |
| **8.6%** | 1,070 | 1,140 | 1,230 | 1,330 | 1,450 |

> [!IMPORTANT]
> 从敏感性分析表可以看出，WACC 变化 1 个百分点，估值可能变化 **20%-30%**。这就是为什么 DCF 被称为"精确的错误"——模型看似精确，但结果高度依赖假设参数。

---

### 3.2 DDM（股利折现模型）— 分红股的经典估值法

#### 3.2.1 Gordon 增长模型

**P = [D_1 / r - g]**

其中：
- P = 股票内在价值
- D_1 = 下一年预期每股股利
- r = 股权资本成本（要求回报率）
- g = 股利永续增长率

#### 3.2.2 适用条件

DDM 模型适用于以下类型的企业：

| 条件 | 说明 |
|------|------|
| ✅ 稳定分红 | 连续多年保持分红，分红率较为稳定 |
| ✅ 增长稳定 | 已过高速增长期，进入稳定发展阶段 |
| ✅ 现金流充裕 | 自由现金流远大于分红金额 |

**A 股适合用 DDM 的公司示例**：长江电力、大秦铁路、中国神华、工商银行

#### 3.2.3 计算示例：长江电力

假设长江电力（600900）的数据如下：

| 指标 | 数值 |
|------|------|
| 当前每股股利 D_0 | 1.06 元 |
| 股利增长率 g | 3%（长期稳定假设） |
| 股权资本成本 r | 7% |

**D_1 = D_0 × (1 + g) = 1.06 × 1.03 = 1.09元**

**P = [1.09 / 7% - 3%] = [1.09 / 0.04] = 27.3元**

**解读**：按 DDM 模型，长江电力的合理估值约为 **27.3 元**。

#### 3.2.4 DDM 的局限性

1. **对 g 和 r 极为敏感**：当 r 接近 g 时，估值趋向无穷大
2. **不适用于不分红企业**：很多成长型企业不分红或分红极少
3. **假设过于简化**：永续等速增长在现实中很少存在
4. **忽视了企业留存收益的再投资价值**

## 四、估值方法选择决策树

面对不同类型的企业，应该选择哪种估值方法？以下决策树可以帮助你快速判断：

```
企业是否盈利？
├── 否（亏损中）
│   ├── 有营业收入？ → 使用 PS（市销率）
│   └── 无收入（早期项目）→ 不适合传统估值，关注赛道和团队
│
└── 是（有利润）
    ├── 利润是否稳定？
    │   ├── 是（稳定盈利）
    │   │   ├── 是否有稳定分红？
    │   │   │   ├── 是 → DDM + PE
    │   │   │   └── 否 → DCF + PE
    │   │   └── 是否是重资产行业？
    │   │       ├── 是（银行/地产）→ PB 为核心
    │   │       └── 否 → PE 为核心
    │   │
    │   └── 否（利润波动大）
    │       ├── 周期行业？ → EV/EBITDA + PB（避免使用 PE）
    │       └── 高增长行业？ → PEG + DCF
    │
    └── 需要跨行业/跨市场对比？ → EV/EBITDA
```

**速查表**：

| 企业类型 | 首选指标 | 辅助指标 | 避免使用 |
|----------|----------|----------|----------|
| 银行 | PB | PE、DDM | PS |
| 消费龙头 | PE | DCF、PEG | PB |
| 周期股 | EV/EBITDA | PB | PE（反向指标） |
| 高成长科技 | PEG | PS、DCF | 静态 PE |
| 公用事业 | DDM | PE | PEG |
| 亏损互联网 | PS | EV/Revenue | PE、PB |
| 制造业 | PE | EV/EBITDA | PS |

## 五、估值的局限性与陷阱

### 5.1 估值陷阱（Valuation Trap）

**定义**：过度依赖单一估值指标而做出错误判断。

**常见误区**：
1. **看 PE 低就买入**：可能是利润一次性暴增（如卖地、卖子公司）导致的虚低 PE
2. **看 PB 低就买入**：资产可能存在大量减值风险
3. **看 PS 低就买入**：可能是毛利率极低的"血汗工厂"

### 5.2 价值陷阱（Value Trap）

**定义**：看起来便宜但永远不会涨的股票。

**典型特征**：
- PE 很低（如 5-8 倍），PB 也很低（如 0.5-0.8 倍）
- 但 ROE 持续下降，盈利能力不断恶化
- 行业处于结构性衰退，没有反转迹象

**经典案例**：部分传统地产股在行业下行周期中，PE 和 PB 持续处于历史低位，但股价继续下跌。因为利润在持续恶化，"低估值"只是表面现象。

**识别方法**：
1. ROE 是否持续下降？
2. 行业是否面临结构性衰退？
3. 管理层是否有改善经营的能力和意愿？
4. 是否存在重大的资产减值风险？

### 5.3 成长陷阱（Growth Trap）

**定义**：为高增长支付过高估值，但增长未能兑现。

**典型特征**：
- PE 极高（如 80-200 倍），市场预期超高增长
- 一旦增速放缓，估值和盈利"戴维斯双杀"
- 股价可能在短期内暴跌 50%-70%

**"戴维斯双杀"机制**：

**股价 = EPS × PE**

当增长放缓时：
- EPS 下降（利润减少）
- PE 倍数收缩（市场降低估值预期）
- 两者叠加，股价暴跌

**示例**：假设某科技公司
- 原来：EPS = 2 元，PE = 60 倍 → 股价 = 120 元
- 增长放缓后：EPS = 1.5 元，PE = 30 倍 → 股价 = 45 元
- 跌幅：**62.5%**

> [!CAUTION]
> 投资中最危险的不是买入低估值的"差公司"，而是在**过高估值**时买入"好公司"。好公司也有合理的买入价格！

## 六、实战案例：贵州茅台多维度估值对比

### 6.1 基础数据

以下为贵州茅台（600519）的关键财务数据（简化示例）：

| 指标 | 数值 |
|------|------|
| 当前股价 | 1,580 元 |
| 总股本 | 12.56 亿股 |
| 总市值 | 19,845 亿元 |
| 最近四季度净利润（TTM） | 747 亿元 |
| 每股净资产 | 135 元 |
| 最近四季度营业收入 | 1,505 亿元 |
| 未来 3 年预期净利润增速 | 14% |
| 每股股利 | 52 元 |
| 有息负债 | 约 0 |
| 现金及等价物 | 约 600 亿元 |
| EBITDA | 约 780 亿元 |

### 6.2 各估值指标计算

#### ① PE 估值

**PE_(TTM) = [19,845 / 747] = 26.6倍**

对比历史和行业：
| 对比维度 | PE |
|----------|-----|
| 茅台当前 PE | 26.6x |
| 茅台近 5 年 PE 中位数 | 35x |
| 白酒行业平均 PE | 25-30x |

**结论**：当前 PE 低于历史中位数，处于合理偏低区间。

#### ② PB 估值

**PB = [1,580 / 135] = 11.7倍**

**解读**：茅台 PB 达到 11.7 倍，远高于净资产。这反映了**品牌溢价和超强盈利能力**。对于轻资产、高 ROE 的企业，PB 参考价值有限。

#### ③ PEG 估值

**PEG = [26.6 / 14] = 1.9**

**解读**：PEG 约 1.9，略高于合理区间（PEG = 1），说明当前估值与增速基本匹配，但不算特别便宜。

#### ④ EV/EBITDA 估值

**EV = 19,845 + 0 - 600 = 19,245亿元**

**[EV / EBITDA] = [19,245 / 780] ≈ 24.7倍**

**解读**：对比消费品行业 10-18 倍的区间，茅台的 EV/EBITDA 溢价明显，反映了市场对其品牌和增长的高度认可。

#### ⑤ DCF 估值

（详见第三章 DCF 五步法计算，结果为每股约 **1,579 元**）

### 6.3 综合估值结论

| 估值方法 | 结果 | 判断 |
|----------|------|------|
| PE（TTM） | 26.6x（低于历史中位数 35x） | ✅ 合理偏低 |
| PB | 11.7x（参考性有限） | ➖ 不适用 |
| PEG | 1.9（略高于 1） | ⚠️ 合理但不便宜 |
| EV/EBITDA | 24.7x（高于行业均值） | ⚠️ 溢价明显 |
| DCF | 每股 ≈ 1,579 元 | ✅ 与当前价格匹配 |

**综合判断**：贵州茅台当前估值处于**合理区间**，既不便宜也不贵。若股价回落至 1,300 元以下（PE 约 22 倍），将具备更好的安全边际。

## 七、估值指标速查表

| 指标 | 公式 | 适用场景 | 判断标准 | 局限性 |
|------|------|----------|----------|--------|
| **PE** | [总市值 / 净利润] | 盈利稳定的企业 | 对比行业均值和历史中位数 | 不适用亏损企业、周期股 |
| **PB** | [总市值 / 净资产] | 银行、地产等重资产行业 | PB < 1 可能低估，结合 ROE 判断 | 轻资产企业参考性低 |
| **PS** | [总市值 / 营业收入] | 亏损企业、互联网/SaaS | PS < 1 可能低估 | 忽视利润率 |
| **PEG** | [PE / 增长率(%)] | 成长型企业 | PEG < 1 低估，PEG > 2 高估 | 依赖增长预测准确性 |
| **EV/EBITDA** | [EV / EBITDA] | 跨企业/跨市场对比 | 对比行业均值 | 忽视资本支出差异 |
| **DCF** | ∑[FCF_t / (1+WACC)^t]+[TV / (1+WACC)^n] | 现金流稳定可预测的企业 | 计算内在价值，对比市价 | 对假设极为敏感 |
| **DDM** | [D_1 / r-g] | 高分红、稳定增长的企业 | 计算内在价值，对比市价 | 不适用低/无分红企业 |

## 八、本章小结

### 核心要点回顾

1. **估值的本质**是寻找价格与价值之间的差距，为投资决策提供依据。

2. **相对估值法**（PE、PB、PS、PEG、EV/EBITDA）通过对比判断估值高低，简单易用但依赖可比性。

3. **绝对估值法**（DCF、DDM）从企业未来现金流出发计算内在价值，理论上更准确但对假设非常敏感。

4. **没有"万能"的估值方法**，必须根据企业类型、行业特征、发展阶段选择合适的估值工具。

5. **警惕三大陷阱**：
   - 估值陷阱：过度依赖单一指标
   - 价值陷阱：看似便宜但基本面持续恶化
   - 成长陷阱：为高增长支付过高溢价

6. **估值是一个区间，而非精确数值**。追求"模糊的正确"远胜于"精确的错误"。

### 实操建议

| 步骤 | 操作 | 工具 |
|------|------|------|
| 第一步 | 了解企业所处行业和发展阶段 | 行业研究报告 |
| 第二步 | 选择 2-3 种适合的估值方法 | 本章决策树 |
| 第三步 | 计算估值并与历史、行业对比 | 同花顺、东方财富 |
| 第四步 | 进行敏感性分析，确定估值区间 | Excel / Python |
| 第五步 | 结合安全边际，制定买入/卖出价格 | 个人投资纪律 |

> **最后的忠告**：估值只是投资决策的起点，而非终点。一个"便宜"的估值如果没有催化剂，可能长期不被市场认可；一个"昂贵"的估值如果增长超预期，可能继续上涨。**估值 + 催化剂 + 风险管理**，三者缺一不可。
