## 1. 技术分析三大假设

所有技术分析方法都建立在以下三个核心假设之上，由查尔斯·道（Charles Dow）最初提出：

### 假设一：市场行为反映一切信息 💡

> *"The market discounts everything."*

- 所有已知信息（基本面、政策面、资金面、情绪面）都已反映在当前价格中
- 技术分析师只需研究价格走势本身，无需额外分析基本面
- **量化视角**：这与"有效市场假说"（EMH）的弱式有效形式一致

### 假设二：价格沿趋势运动 📊

> *"Prices move in trends."*

- 价格一旦形成趋势，更倾向于沿趋势方向继续运动，而非随机波动
- 趋势会持续，直到有明确信号表明趋势已经反转
- **量化视角**：这是动量策略（Momentum Strategy）的理论基础

### 假设三：历史会重演 🔄

> *"History tends to repeat itself."*

- 市场参与者在类似情境下会表现出类似的行为模式
- 因此，过去出现过的价格形态和指标信号在未来仍可能有效
- **量化视角**：这是模式识别和统计回测的理论基础

> ⚠️ **批判性思考**：这三大假设并非绝对真理。市场结构不断变化，过度依赖历史模式可能导致"过拟合"（Overfitting）。量化交易者需要在信任模式与防范失效之间找到平衡。

## 2. 均线系统（MA）

均线（Moving Average）是技术分析中最基础、最重要的指标之一，通过计算一定时间段内的平均价格来平滑价格波动，揭示趋势方向。

### 2.1 简单移动平均线（SMA）

#### 公式推导

**SMA(n) = [1 / n] ∑_(i=0)^(n-1) P_(t-i) = [ (P_t + P_(t-1) + ... + P_(t-n+1)) / n ]**

其中：
- P_t = 第 t 日的收盘价
- n = 时间窗口（周期数）

#### SMA的特点

| 优点 | 缺点 |
|------|------|
| 计算简单直观 | 对所有数据赋予相同权重 |
| 能有效平滑噪声 | 对最新价格变化反应迟钝 |
| 适合长期趋势判断 | 存在明显的滞后性（Lag） |

### 2.2 指数移动平均线（EMA）

#### 公式推导

EMA 给予近期价格更高的权重，以减少滞后性：

**EMA_t = α · P_t + (1 - α) · EMA_(t-1)**

其中，平滑系数 α 的计算公式为：

**α = [2 / n + 1]**

**递归展开**：

**EMA_t = α · P_t + α(1-α) · P_(t-1) + α(1-α)^2 · P_(t-2) + ·s**

可以看出，越近的价格权重越大，权重按指数衰减。

#### 举例：计算12日EMA

**α = [2 / 12 + 1] = [2 / 13] ≈ 0.1538**

**EMA_(12,t) = 0.1538 × P_t + 0.8462 × EMA_(12,t-1)**

#### SMA vs EMA 对比

| 特性 | SMA | EMA |
|------|-----|-----|
| 权重分配 | 等权重 | 指数衰减（近期权重大） |
| 灵敏度 | 较低 | 较高 |
| 滞后性 | 较大 | 较小 |
| 噪声过滤 | 较好 | 一般 |
| 适用场景 | 长期趋势 | 短期交易信号 |
| 常用指标 | MA20, MA60 | MACD中的快慢线 |

### 2.3 常用均线参数及含义

| 均线 | 周期 | 别称 | 含义 |
|------|------|------|------|
| MA5 | 5日 | 攻击线 | 超短线趋势，反映一周内平均成本 |
| MA10 | 10日 | 操盘线 | 短线趋势，反映两周内平均成本 |
| MA20 | 20日 | 辅助线/月线 | 中短线趋势，反映一个月内平均成本 |
| MA60 | 60日 | 决策线/季线 | 中线趋势，反映一个季度内平均成本 |
| MA120 | 120日 | 趋势线/半年线 | 中长线趋势，牛熊分界参考 |
| MA250 | 250日 | 生命线/年线 | 长期趋势，重要的牛熊分界线 |

### 2.4 金叉与死叉

#### 金叉（Golden Cross）✨
- **定义**：短期均线从下方穿越长期均线
- **信号**：看涨买入信号
- **经典组合**：MA5上穿MA10，MA10上穿MA20

#### 死叉（Death Cross）💀
- **定义**：短期均线从上方穿越长期均线
- **信号**：看跌卖出信号
- **经典组合**：MA5下穿MA10，MA10下穿MA20

> ⚠️ **注意**：在震荡市中，金叉和死叉会频繁出现，产生大量假信号，此时不宜单独使用。

### 2.5 均线排列

#### 多头排列（Bullish Alignment）📈
```
MA5  ————————————————  （最上方）
MA10 ————————————————
MA20 ————————————————
MA60 ————————————————  （最下方）
```
- **含义**：短期均线在上，长期均线在下，各周期平均成本逐步降低
- **信号**：强势上涨趋势，持股不动

#### 空头排列（Bearish Alignment）📉
```
MA60 ————————————————  （最上方）
MA20 ————————————————
MA10 ————————————————
MA5  ————————————————  （最下方）
```
- **含义**：长期均线在上，短期均线在下，各周期持有者均被套牢
- **信号**：强势下跌趋势，空仓等待

### 2.6 葛兰碧八大买卖法则

约瑟夫·葛兰碧（Joseph Granville）提出的均线交易系统，是均线应用的经典框架：

#### 四大买入法则

| 法则 | 条件 | 说明 |
|------|------|------|
| **买1** | 均线由下降转为走平或上升，价格从下方突破均线 | 趋势转变的初始信号 |
| **买2** | 价格回落到均线附近获得支撑后反弹 | 上升趋势中的回调买入 |
| **买3** | 价格下跌到均线附近但未跌破，随后反弹 | 均线支撑确认 |
| **买4** | 价格急跌远离均线（乖离率过大） | 超卖反弹的短线买入 |

#### 四大卖出法则

| 法则 | 条件 | 说明 |
|------|------|------|
| **卖1** | 均线由上升转为走平或下降，价格从上方跌破均线 | 趋势转变的初始信号 |
| **卖2** | 价格反弹到均线附近遇阻后回落 | 下降趋势中的反弹卖出 |
| **卖3** | 价格上涨到均线附近但未突破，随后回落 | 均线阻力确认 |
| **卖4** | 价格急涨远离均线（乖离率过大） | 超买回调的短线卖出 |

**乖离率（BIAS）** 的计算公式：

**BIAS(n) = [P_t - MA(n) / MA(n)] × 100%**

当乖离率绝对值过大时，价格有向均线回归的倾向（均值回归效应）。

## 3. MACD指标

MACD（Moving Average Convergence Divergence，指数平滑异同移动平均线）由杰拉德·阿佩尔（Gerald Appel）于1979年发明，是最常用的趋势跟踪和动量指标之一。

### 3.1 完整公式推导

#### 第一步：计算快慢EMA

**EMA_(fast)(12) = [2 / 13] × P_t + [11 / 13] × EMA_(12,t-1)**

**EMA_(slow)(26) = [2 / 27] × P_t + [25 / 27] × EMA_(26,t-1)**

#### 第二步：计算DIF（快慢线差值）

**DIF = EMA(12) - EMA(26)**

- DIF > 0：短期均线在长期均线之上 → 多头趋势
- DIF < 0：短期均线在长期均线之下 → 空头趋势

#### 第三步：计算DEA（信号线）

**DEA = EMA(DIF, 9) = [2 / 10] × DIF_t + [8 / 10] × DEA_(t-1)**

DEA是DIF的9日EMA，更加平滑，用于产生交易信号。

#### 第四步：计算MACD柱（红绿柱）

**MACD_BAR = 2 × (DIF - DEA)**

> 📝 乘以2是为了放大视觉效果，不同软件可能有差异。

### 3.2 MACD的核心信号

#### 3.2.1 金叉与死叉

| 信号 | 条件 | 含义 |
|------|------|------|
| **MACD金叉** | DIF从下方穿越DEA | 买入信号 |
| **MACD死叉** | DIF从上方穿越DEA | 卖出信号 |
| **零轴上方金叉** | 在零轴上方发生金叉 | 强势买入信号 |
| **零轴下方死叉** | 在零轴下方发生死叉 | 强势卖出信号 |

#### 3.2.2 零轴的意义

```
        DIF
零轴上方  ————  多头市场
━━━━━━━━━━━━━━━━━━  ← 零轴（DIF = 0, 即 EMA12 = EMA26）
零轴下方  ————  空头市场
```

- **DIF在零轴上方运行**：中期趋势向上
- **DIF在零轴下方运行**：中期趋势向下
- **DIF穿越零轴**：趋势发生根本性转变

#### 3.2.3 MACD柱的变化

- 🔴 **红柱（MACD_BAR > 0）**：DIF > DEA，多头占优
  - 红柱变长 → 多头力量增强
  - 红柱变短 → 多头力量减弱（准备卖出的预警）
- 🟢 **绿柱（MACD_BAR < 0）**：DIF < DEA，空头占优
  - 绿柱变长 → 空头力量增强
  - 绿柱变短 → 空头力量减弱（准备买入的预警）

### 3.3 背离详解

背离是MACD最有价值的信号之一，用于预判趋势反转。

#### 3.3.1 顶背离（Bearish Divergence）

```
价格:    高点A ————→  更高点B
MACD:   高点A' ————→  更低点B'  ← 背离！
```

- **定义**：价格创新高，但MACD（DIF或MACD柱）没有创新高，反而走低
- **含义**：虽然价格还在上涨，但上涨动能已经减弱
- **信号**：看跌反转信号，出现后应考虑减仓

#### 3.3.2 底背离（Bullish Divergence）

```
价格:    低点A ————→  更低点B
MACD:   低点A' ————→  更高点B'  ← 背离！
```

- **定义**：价格创新低，但MACD没有创新低，反而走高
- **含义**：虽然价格还在下跌，但下跌动能已经减弱
- **信号**：看涨反转信号，出现后应关注买入机会

#### 3.3.3 背离的使用要点

1. **多次背离更可靠**：出现第二次、第三次背离时，反转概率大幅增加
2. **大周期背离更有效**：周线背离比日线背离更可靠
3. **结合其他指标确认**：不要单独依赖背离信号，应结合量价、K线形态等
4. **警惕"背了又背"**：在强趋势中，背离信号可能持续失效

### 3.4 MACD实战策略

#### 策略一：零轴上方金叉买入法

- **条件**：MACD在零轴上方发生金叉（DIF上穿DEA）
- **逻辑**：大趋势向上（零轴上方），短期调整结束（金叉）
- **胜率**：约60-65%

#### 策略二：底背离 + 金叉共振

- **条件**：先出现底背离，随后DIF上穿DEA形成金叉
- **逻辑**：动能衰减（背离）+ 趋势转折确认（金叉）
- **优势**：信号更可靠，但出现频率较低

#### 策略三：红绿柱缩放

- **买入**：绿柱持续缩短直至翻红
- **卖出**：红柱持续缩短直至翻绿
- **优势**：比金叉/死叉更早发出信号

## 4. RSI（相对强弱指标）

RSI（Relative Strength Index）由 J. Welles Wilder Jr. 于1978年提出，用于衡量价格变动的速度和幅度。

### 4.1 公式推导

#### 第一步：计算涨跌幅

**Δ P_t = P_t - P_(t-1)**

#### 第二步：分离上涨和下跌

**U_t = max(Δ P_t, 0) \text（上涨幅度，下跌时为0）**

**D_t = max(-Δ P_t, 0) \text（下跌幅度，上涨时为0）**

#### 第三步：计算平均涨跌幅（使用EMA或SMA）

**平均U_n = [1 / n]∑_(i=1)^(n) U_(t-i+1) \text（初始值，后续用EMA平滑）**

**平均D_n = [1 / n]∑_(i=1)^(n) D_(t-i+1)**

递推公式（Wilder平滑法）：

**平均U_t = [ ((n-1) · 平均U_(t-1) + U_t) / n ]**

**平均D_t = [ ((n-1) · 平均D_(t-1) + D_t) / n ]**

#### 第四步：计算相对强弱比

**RS = [ 平均U_n / 平均D_n ]**

#### 第五步：计算RSI

**RSI = 100 - [100 / 1 + RS] = [ (100 × 平均U_n) / (平均U_n + 平均D_n) ]**

### 4.2 RSI的取值范围与解读

| RSI区域 | 值范围 | 市场状态 | 操作建议 |
|---------|-------|---------|---------|
| 极度超买 | > 80 | 严重超买，上涨过快 | 强烈卖出信号 |
| 超买区 | 70-80 | 超买，可能回调 | 逐步减仓 |
| 正常区 | 30-70 | 多空均衡 | 观望或顺势操作 |
| 超卖区 | 20-30 | 超卖，可能反弹 | 逐步建仓 |
| 极度超卖 | < 20 | 严重超卖，下跌过快 | 强烈买入信号 |

### 4.3 RSI常用参数

| 参数 | 适用场景 |
|------|---------|
| RSI(6) | 超短线交易，灵敏度高但假信号多 |
| RSI(14) | 最常用，Wilder推荐的默认参数 |
| RSI(21) | 中线交易，信号更平滑可靠 |

### 4.4 RSI背离

与MACD背离原理相同：

- **RSI顶背离**：价格新高 + RSI未新高 → 看跌信号
- **RSI底背离**：价格新低 + RSI未新低 → 看涨信号

### 4.5 RSI的特殊用法

#### 失败摆动（Failure Swing）

**看涨失败摆动**：
1. RSI跌入超卖区（< 30）
2. RSI反弹并突破30
3. RSI再次回落但 **未跌破前低**
4. RSI再次向上突破前高 → 买入信号

**看跌失败摆动**：与上述相反，出现在超买区。

## 5. KDJ（随机指标）

KDJ指标由乔治·莱恩（George Lane）发明，全称为"随机震荡指标"（Stochastic Oscillator），用于衡量收盘价在近期价格区间中的相对位置。

### 5.1 计算公式

#### 第一步：计算RSV（未成熟随机值）

**RSV = [C_t - L_n / H_n - L_n] × 100**

其中：
- C_t = 当日收盘价
- L_n = 最近 n 日的最低价（通常 n=9）
- H_n = 最近 n 日的最高价

#### 第二步：计算K值

**K_t = [2 / 3] × K_(t-1) + [1 / 3] × RSV_t**

K值初始值通常设为50。

#### 第三步：计算D值

**D_t = [2 / 3] × D_(t-1) + [1 / 3] × K_t**

D值初始值通常设为50。

#### 第四步：计算J值

**J_t = 3K_t - 2D_t**

> 📝 **J值的特殊性**：J值可以超过100或低于0，这使得它在判断极端超买超卖时特别有效。

### 5.2 KDJ取值范围与解读

| 指标 | 超买区 | 正常区 | 超卖区 |
|------|--------|--------|--------|
| K值 | > 80 | 20-80 | < 20 |
| D值 | > 80 | 20-80 | < 20 |
| J值 | > 100 | 0-100 | < 0 |

### 5.3 KDJ交易信号

| 信号 | 条件 | 含义 |
|------|------|------|
| **KDJ金叉** | K线上穿D线 | 买入信号 |
| **KDJ死叉** | K线下穿D线 | 卖出信号 |
| **超卖区金叉** | K < 20时上穿D | 强烈买入信号 |
| **超买区死叉** | K > 80时下穿D | 强烈卖出信号 |
| **J值超买** | J > 100 | 极度超买，短线见顶 |
| **J值超卖** | J < 0 | 极度超卖，短线见底 |

### 5.4 KDJ的优缺点

| 优点 | 缺点 |
|------|------|
| 对短线转折点敏感 | 在单边趋势中频繁发出假信号 |
| 信号明确，易于量化 | 钝化现象（持续超买/超卖） |
| 适合震荡市场 | 不适合趋势明显的市场 |

> 💡 **应对钝化**：当KDJ在超买区（> 80）持续运行不回落时，说明市场处于强势上涨中。此时不应盲目卖出，而应结合MACD、均线等趋势指标判断。

## 6. 布林带（BOLL）

布林带（Bollinger Bands）由约翰·布林格（John Bollinger）于1980年代发明，基于统计学的标准差概念来度量价格的波动性。

### 6.1 计算公式

#### 中轨（Middle Band）

**MB = SMA(n) = [1 / n]∑_(i=0)^(n-1) P_(t-i)**

通常取 n = 20。

#### 标准差（Standard Deviation）

**σ = √[1 / n]∑_(i=0)^(n-1)(P_(t-i) - MB)^2**

#### 上轨（Upper Band）

**UB = MB + k · σ**

通常取 k = 2。

#### 下轨（Lower Band）

**LB = MB - k · σ**

#### 带宽（Bandwidth）

**BW = [UB - LB / MB] × 100%**

#### 百分比B指标（%B）

**%B = [P_t - LB / UB - LB]**

- %B > 1：价格在上轨之上（超买）
- %B < 0：价格在下轨之下（超卖）
- %B = 0.5：价格在中轨

### 6.2 统计学原理

根据正态分布理论：
- 价格在 MB \pm 1σ 范围内的概率约 **68.27%**
- 价格在 MB \pm 2σ 范围内的概率约 **95.45%**
- 价格在 MB \pm 3σ 范围内的概率约 **99.73%**

因此，当 k = 2 时，价格在布林带内运行的理论概率约为95%，突破上下轨为小概率事件。

### 6.3 布林带的形态与信号

#### 6.3.1 开口（Expansion）

```
  上轨 ╱————————————————
  中轨 ————————————————
  下轨 ╲————————————————
```

- **含义**：波动性增大，趋势加速
- **应用**：
  - 向上开口 + 价格沿上轨运行 → 强势上涨，持股
  - 向下开口 + 价格沿下轨运行 → 强势下跌，空仓

#### 6.3.2 缩口（Squeeze）

```
  上轨 ╲————————╱
  中轨 ————————————
  下轨 ╱————————╲
```

- **含义**：波动性极低，价格横盘整理
- **应用**：缩口是大幅波动的前兆（"平静前的暴风雨"），突破方向不确定，需要等待

#### 6.3.3 上轨/下轨触碰

| 触碰位置 | 趋势市场 | 震荡市场 |
|---------|---------|---------|
| 触碰上轨 | 强势信号，可能继续沿上轨上行 | 超买信号，可能回落 |
| 触碰下轨 | 弱势信号，可能继续沿下轨下行 | 超卖信号，可能反弹 |

### 6.4 布林带交易策略

#### 策略一：均值回归策略（震荡市）
- **买入**：价格触及下轨后回升到下轨上方
- **卖出**：价格触及上轨后回落到上轨下方
- **止损**：价格跌破下轨2%以下

#### 策略二：突破跟随策略（趋势市）
- **买入**：缩口后价格向上突破上轨，成交量放大
- **卖出**：缩口后价格向下突破下轨，成交量放大
- **关键**：必须有成交量配合，否则可能是假突破

#### 策略三：中轨趋势策略
- 价格在中轨（MA20）上方运行 → 中期看多
- 价格在中轨下方运行 → 中期看空
- 中轨可作为趋势交易的止损参考

## 7. 成交量指标

> *"价格是表象，成交量是本质。"* — 技术分析格言

### 7.1 成交量基础

成交量（Volume）代表一定时间内的成交股数或成交金额，是衡量市场活跃度和资金参与度的核心指标。

#### 成交量的基本类型

| 类型 | 定义 | 含义 |
|------|------|------|
| 放量 | 成交量显著高于前期平均水平 | 市场参与度提高，可能有重要信号 |
| 缩量 | 成交量显著低于前期平均水平 | 市场参与度降低，观望情绪浓厚 |
| 天量 | 创阶段性新高的极端放量 | 可能见顶，大量资金换手 |
| 地量 | 创阶段性新低的极端缩量 | 可能见底，卖压衰竭 |
| 温和放量 | 成交量逐步温和增大 | 健康的趋势发展 |
| 突然放量 | 成交量突然爆发式增大 | 异常信号，需警惕 |

### 7.2 OBV（能量潮，On-Balance Volume）

由乔·格兰维尔（Joe Granville）提出，通过累积成交量来衡量买卖力量。

#### 计算公式

**OBV_t = \begincases OBV_(t-1) + V_t & \textif P_t > P_(t-1) \text（上涨日） 
 OBV_(t-1) - V_t & \textif P_t < P_(t-1) \text（下跌日） 
 OBV_(t-1) & \textif P_t = P_(t-1) \text（平盘日） \endcases**

其中 V_t 为第 t 日成交量。

#### OBV的解读

| 信号 | 含义 |
|------|------|
| OBV持续上升 + 价格上涨 | 上涨趋势健康，资金持续流入 |
| OBV持续上升 + 价格横盘 | 主力可能在悄悄建仓 |
| OBV走平 + 价格上涨 | 上涨缺乏量能支持，可能是假突破 |
| OBV下降 + 价格上涨 | 价量背离，上涨不可持续 |
| OBV下降 + 价格下跌 | 下跌趋势确认，资金持续流出 |

### 7.3 VWAP（成交量加权平均价）

VWAP（Volume Weighted Average Price）是机构投资者和量化交易中广泛使用的基准价格。

#### 计算公式

**VWAP = [ ∑(P_i × V_i) / ∑V_i ]**

其中：
- P_i = 第 i 笔交易的价格（通常用每个时间段的典型价格：(H+L+C)/3）
- V_i = 第 i 笔交易的成交量

#### VWAP的应用

| 应用场景 | 说明 |
|---------|------|
| **交易基准** | 机构投资者用VWAP评估交易执行质量 |
| **支撑/阻力** | 日内交易中，VWAP常作为动态支撑/阻力 |
| **趋势判断** | 价格在VWAP上方 → 日内偏多；下方 → 日内偏空 |
| **量化策略** | VWAP算法交易策略（按VWAP价格执行大额订单） |

> 💡 **量化应用**：VWAP拆单策略是机构最常用的算法交易策略之一。目标是让大额订单的平均成交价尽可能接近VWAP，以减少市场冲击。

## 8. 指标组合使用建议

### 8.1 不同类型指标的互补

| 指标类型 | 代表指标 | 适用环境 | 功能 |
|---------|---------|---------|------|
| **趋势指标** | MA, MACD | 趋势市场 | 判断趋势方向和强度 |
| **震荡指标** | RSI, KDJ | 震荡市场 | 判断超买超卖和转折点 |
| **波动指标** | 布林带 | 所有市场 | 衡量波动率和价格区间 |
| **量能指标** | OBV, VWAP | 所有市场 | 确认价格走势的真实性 |

### 8.2 经典指标组合

#### 组合一：MACD + RSI + 均线

- **均线**确定大趋势方向
- **MACD**确认趋势强度和动量
- **RSI**寻找超买超卖的入场时机

#### 组合二：布林带 + KDJ + 成交量

- **布林带**确定价格波动区间
- **KDJ**判断短线买卖时机
- **成交量**确认信号的可靠性

#### 组合三：均线 + MACD + 成交量（"量价时空"体系）

- **均线**定趋势
- **MACD**定动量和背离
- **成交量**定资金流向
- 三者共振时，信号最可靠

### 8.3 指标使用的黄金法则

1. **不要同时使用太多指标**：3-4个足够，过多会导致"分析瘫痪"
2. **选择互补的指标**：趋势指标 + 震荡指标 + 量能指标
3. **不要使用同类指标**：比如同时用RSI和KDJ意义不大（它们衡量类似的东西）
4. **先确定市场环境**：趋势市用趋势指标为主，震荡市用震荡指标为主

## 9. 技术指标的局限性

### 9.1 固有缺陷

| 局限 | 说明 | 应对方法 |
|------|------|---------|
| **滞后性** | 所有基于历史数据的指标都有滞后性 | 结合价格行为（Price Action）分析 |
| **假信号** | 震荡市中趋势指标产生大量假信号 | 加入过滤条件，如成交量确认 |
| **参数敏感** | 不同参数可能给出完全不同的信号 | 在不同市场环境中优化参数 |
| **过拟合风险** | 历史回测效果好不代表未来有效 | 使用样本外测试和滚动验证 |
| **忽视基本面** | 技术指标不考虑公司价值和宏观经济 | 技术分析与基本面分析结合使用 |

### 9.2 技术指标失效的场景

- **重大消息发布**：财报、政策、黑天鹅事件等导致价格跳空
- **流动性极低**：小盘股或者盘后交易中，技术指标参考价值有限
- **市场操纵**：庄家/主力可能刻意制造假的技术信号
- **趋势/震荡切换**：市场从趋势转为震荡（或反之）时，原有指标策略可能失效

### 9.3 量化交易者的正确态度

> 📌 **技术指标是工具，不是圣杯。**

1. **概率思维**：每个信号都有成功和失败的概率，关键是让成功的收益大于失败的损失
2. **系统性交易**：将指标信号系统化为交易规则，通过回测验证有效性
3. **风险管理第一**：任何信号都必须配合严格的止损和仓位管理
4. **持续学习**：市场不断演变，策略需要持续更新和优化
