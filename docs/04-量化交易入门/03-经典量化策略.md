## 策略分类框架

在深入学习每个策略之前，先建立一个整体的分类视角：

```
                        量化策略分类
                    ┌───────┴────────┐
                趋势类策略          反趋势类策略
              ┌────┴─────┐       ┌────┴─────┐
          趋势跟随    动量策略   均值回归    配对交易
          │           │         │           │
        均线突破    截面动量    布林带策略   统计套利
        通道突破    时序动量    RSI反转     协整套利
        海龟交易    因子动量    网格交易
```

### 按核心逻辑分类

| 类别 | 核心假设 | 代表策略 | 适用市场 |
|------|---------|---------|---------|
| **趋势跟随** | 价格存在惯性，趋势会延续 | 均线交叉、海龟交易法 | 趋势市 |
| **动量** | 强者恒强，过去表现好的未来继续好 | 截面动量、时序动量 | 中长期市场 |
| **均值回归** | 价格偏离均值后会回归 | 布林带、配对交易 | 震荡市 |
| **统计套利** | 统计关系的暂时偏离会修复 | 配对交易、指数套利 | 相关性市场 |
| **因子投资** | 特定因子能解释超额收益 | 多因子模型、Smart Beta | 股票市场 |

### 策略选择指南

> 📌 没有"最好"的策略，只有"最适合当前市场环境"的策略。

| 市场环境 | 推荐策略类型 | 原因 |
|---------|-------------|------|
| 🐂 牛市（单边上涨） | 趋势跟随、动量 | 趋势明确，顺势而为 |
| 🐻 熊市（单边下跌） | 趋势跟随（做空）、均值回归 | 反弹做空或抓反弹 |
| 🦘 震荡市 | 均值回归、网格交易 | 无明确趋势，高抛低吸 |
| 🔀 转折期 | 因子轮动、多策略组合 | 不确定方向，分散风险 |

## 均线交叉策略

### 📖 原理

均线交叉策略（Moving Average Crossover）是最经典、最容易理解的趋势跟随策略。

**核心逻辑**：
- **短期均线上穿长期均线**（金叉）→ 买入信号 📈
- **短期均线下穿长期均线**（死叉）→ 卖出信号 📉

**数学表达**：

**MA_n(t) = [1 / n]∑_(i=0)^(n-1) P(t-i)**

其中 P(t) 是第 t 天的收盘价，n 是均线周期。

**交易信号**：

**\textSignal(t) = \begincases
\text买入 & \textif MA_(fast)(t) > MA_(slow)(t) \text and MA_(fast)(t-1) \leq MA_(slow)(t-1) 

\text卖出 & \textif MA_(fast)(t) < MA_(slow)(t) \text and MA_(fast)(t-1) \geq MA_(slow)(t-1) 

\text持有 & \textotherwise
\endcases**

### 参数选择

不同的均线参数组合适用于不同的交易风格：

| 参数组合 | 交易频率 | 信号灵敏度 | 适用场景 |
|---------|---------|-----------|---------|
| **5/20** | 高 | 灵敏，容易产生假信号 | 短线交易、波动较大的市场 |
| **10/30** | 中 | 平衡 | 中线交易、大多数市场 |
| **20/60** | 低 | 迟钝，但信号可靠性高 | 中长线交易、趋势明显的市场 |
| **50/200** | 极低 | 非常迟钝 | 长期投资、黄金交叉/死亡交叉 |

### 优缺点分析

| ✅ 优点 | ❌ 缺点 |
|--------|--------|
| 逻辑简单，容易理解和实现 | 在震荡市中频繁产生假信号 |
| 能捕捉大趋势行情 | 信号滞后，入场和出场都不在最优点 |
| 参数少，不容易过度拟合 | 大趋势结束后可能吐回大部分利润 |
| 适用于多种市场和资产 | 无法预测趋势方向，只能跟随 |

### Python 实现

```python
import pandas as pd
import numpy as np

def ma_cross_strategy(df, fast_period=5, slow_period=20):
    """
    均线交叉策略

    参数:
        df: DataFrame, 必须包含 'close' 列
        fast_period: 短期均线周期
        slow_period: 长期均线周期

    返回:
        DataFrame, 包含信号和持仓列
    """
    df = df.copy()

    # 计算均线
    df['fast_ma'] = df['close'].rolling(window=fast_period).mean()
    df['slow_ma'] = df['close'].rolling(window=slow_period).mean()

    # 生成信号
    # 1: 持有多头, 0: 空仓
    df['signal'] = 0
    df.loc[df['fast_ma'] > df['slow_ma'], 'signal'] = 1

    # 交易信号（只在交叉点产生）
    df['trade'] = df['signal'].diff()
    # trade = 1: 买入（金叉）
    # trade = -1: 卖出（死叉）

    # 计算策略收益
    df['daily_return'] = df['close'].pct_change()
    df['strategy_return'] = df['signal'].shift(1) * df['daily_return']

    # 累计收益
    df['cum_return'] = (1 + df['strategy_return']).cumprod()
    df['cum_benchmark'] = (1 + df['daily_return']).cumprod()

    return df

# 使用示例
# result = ma_cross_strategy(df, fast_period=10, slow_period=30)
# buy_signals = result[result['trade'] == 1]
# sell_signals = result[result['trade'] == -1]
# print(f"总交易次数: {len(buy_signals) + len(sell_signals)}")
# print(f"策略总收益: {result['cum_return'].iloc[-1] - 1:.2%}")
```

### 策略改进方向

1. **添加过滤器**：用成交量确认突破的有效性
2. **使用EMA替代SMA**：指数移动平均线对近期价格更敏感
3. **添加止损**：设置固定百分比或ATR止损
4. **多时间框架确认**：在日线和周线同时确认趋势方向

## 动量策略（Momentum）

### 📖 原理

动量策略基于一个经过广泛学术研究验证的市场异象：

> **"过去表现好的资产，在未来一段时间内倾向于继续表现好；反之亦然。"**

这一现象被称为**动量效应**（Momentum Effect），由 Jegadeesh 和 Titman 在 1993 年的经典论文中系统性地证实。

### 动量效应的解释

| 解释角度 | 内容 |
|---------|------|
| **行为金融学** | 投资者对信息反应不足（underreaction），导致价格缓慢调整 |
| **羊群效应** | 上涨吸引更多买入，形成正反馈循环 |
| **确认偏差** | 投资者倾向于关注支持自己观点的信息 |
| **风险补偿** | 动量股票可能承担了更高的风险，因此获得更高的回报 |

### 实现方法

#### 截面动量（Cross-Sectional Momentum）

在某一时点，比较所有股票的过去表现，买入表现最好的一组，卖出表现最差的一组。

```python
def cross_sectional_momentum(price_df, lookback=20, top_n=10):
    """
    截面动量策略

    参数:
        price_df: DataFrame, 每列是一只股票的收盘价，index为日期
        lookback: 回望期（天数），计算过去N天的收益率
        top_n: 选取收益率排名前N的股票

    返回:
        DataFrame, 每天应持有的股票及权重
    """
    # 计算过去 lookback 天的收益率
    returns = price_df.pct_change(lookback)

    # 每天选取收益率最高的 top_n 只股票
    holdings = pd.DataFrame(index=returns.index, columns=price_df.columns)

    for date in returns.index:
        if returns.loc[date].dropna().empty:
            continue
        # 排名
        ranked = returns.loc[date].dropna().rank(ascending=False)
        # 选取前N名
        selected = ranked[ranked <= top_n].index
        # 等权重分配
        holdings.loc[date, selected] = 1.0 / top_n

    holdings = holdings.fillna(0)
    return holdings

# 使用示例:
# 假设 all_prices 是包含多只股票价格的 DataFrame
# holdings = cross_sectional_momentum(all_prices, lookback=20, top_n=10)
```

#### 时序动量（Time-Series Momentum）

不与其他资产比较，而是看单个资产自身的过去表现。

```python
def time_series_momentum(df, lookback=20):
    """
    时序动量策略：如果过去N天收益为正，则做多；否则空仓

    参数:
        df: DataFrame, 包含 'close' 列
        lookback: 回望期

    返回:
        DataFrame, 包含信号
    """
    df = df.copy()

    # 过去N天收益率
    df['momentum'] = df['close'].pct_change(lookback)

    # 信号：收益率为正则做多，否则空仓
    df['signal'] = 0
    df.loc[df['momentum'] > 0, 'signal'] = 1

    return df
```

### 动量因子构建

常用的动量因子计算方法：

| 因子名称 | 计算公式 | 说明 |
|---------|---------|------|
| **简单收益率动量** | MOM_n = [ P_t / P_(t-n) ] - 1 | 最基本的动量因子 |
| **跳过近期的动量** | MOM_(12,1) = [ P_(t-21) / P_(t-252) ] - 1 | 跳过最近1个月，避免短期反转 |
| **风险调整动量** | [MOM_n / σ_n] | 用波动率标准化，避免高波动股票的影响 |
| **信息离散度** | ID = σ(r_(monthly)) | 月度收益率的波动率 |

> ⚠️ **注意**：经典的动量策略通常使用**过去12个月的收益率，跳过最近1个月**（即 MOM_12,1）。这是因为最近1个月的价格可能存在短期反转效应。

## 均值回归策略（Mean Reversion）

### 📖 原理

均值回归策略基于一个直觉性的假设：

> **"价格不会永远偏离其'正常'水平，当偏离过大时，价格倾向于回到均值附近。"**

数学表达（Ornstein-Uhlenbeck过程）：

**dX_t = θ(μ - X_t)dt + σ dW_t**

其中：
- μ：长期均值
- θ：回归速度（θ 越大，回归越快）
- σ：波动率
- W_t：维纳过程（布朗运动）

### 布林带策略实现

布林带（Bollinger Bands）是最经典的均值回归指标，由 John Bollinger 在 1980 年代发明。

#### 布林带计算

**\beginaligned
\text中轨 &= MA_n 

\text上轨 &= MA_n + k × σ_n 

\text下轨 &= MA_n - k × σ_n
\endaligned**

其中 MA_n 是 n 日移动平均线，σ_n 是 n 日标准差，k 通常取 2。

#### 交易规则

| 条件 | 操作 | 逻辑 |
|------|------|------|
| 价格触及或跌破**下轨** | 买入 | 价格超卖，预期回归均值 |
| 价格回到**中轨** | 平仓（止盈） | 价格已回归均值 |
| 价格触及或突破**上轨** | 卖出/做空 | 价格超买，预期回归均值 |
| 价格跌破下轨2倍标准差 | 止损 | 可能不是回归，而是趋势突破 |

#### Python 实现

```python
def bollinger_band_strategy(df, period=20, num_std=2):
    """
    布林带均值回归策略

    参数:
        df: DataFrame, 包含 'close' 列
        period: 均线周期
        num_std: 标准差倍数

    返回:
        DataFrame, 包含布林带和交易信号
    """
    df = df.copy()

    # 计算布林带
    df['bb_mid'] = df['close'].rolling(window=period).mean()
    df['bb_std'] = df['close'].rolling(window=period).std()
    df['bb_upper'] = df['bb_mid'] + num_std * df['bb_std']
    df['bb_lower'] = df['bb_mid'] - num_std * df['bb_std']

    # %B 指标：价格在布林带中的相对位置
    df['pct_b'] = (df['close'] - df['bb_lower']) / (df['bb_upper'] - df['bb_lower'])

    # 生成信号
    df['signal'] = 0
    df['position'] = 0

    in_position = False
    for i in range(1, len(df)):
        if not in_position:
            # 价格跌破下轨 → 买入
            if df['close'].iloc[i] < df['bb_lower'].iloc[i]:
                df.iloc[i, df.columns.get_loc('signal')] = 1  # 买入
                in_position = True
        else:
            # 价格回到中轨 → 卖出（止盈）
            if df['close'].iloc[i] > df['bb_mid'].iloc[i]:
                df.iloc[i, df.columns.get_loc('signal')] = -1  # 卖出
                in_position = False
            # 价格跌破下轨太多 → 止损
            elif df['close'].iloc[i] < df['bb_lower'].iloc[i] - df['bb_std'].iloc[i]:
                df.iloc[i, df.columns.get_loc('signal')] = -1  # 止损
                in_position = False

    return df
```

### 配对交易简介

配对交易（Pairs Trading）是均值回归策略的高级形式，利用两只**高度相关**的股票之间的价差进行交易。

#### 基本流程

```
1. 寻找高相关性的股票对
   （如：工商银行 vs 建设银行，贵州茅台 vs 五粮液）
        ↓
2. 检验协整关系（Cointegration Test）
        ↓
3. 计算价差（Spread = A - β × B）
        ↓
4. 当价差偏离均值超过阈值时交易
   • 价差过大：做空A + 做多B
   • 价差过小：做多A + 做空B
        ↓
5. 价差回归均值时平仓获利
```

#### 关键数学概念

- **相关性**：\rho_(AB) = [Cov(A, B) / σ_A · σ_B]
- **协整关系**：两个非平稳序列的线性组合是平稳的
- **价差 Z-score**：Z = [ (Spread - μ_Spread) / σ_Spread ]
- 当 |Z| > 2 时开仓，|Z| < 0.5 时平仓

## 海龟交易法

### 📖 起源故事

1983年，著名商品投机者 **Richard Dennis** 和他的朋友 **William Eckhardt** 进行了一场辩论：

- Dennis 认为：**交易可以被教授**，任何人只要学会了正确的规则就能成功交易
- Eckhardt 认为：**交易需要天赋**，不是每个人都能成为成功的交易者

为了验证各自的观点，他们招募了一批没有交易经验的普通人（包括会计师、保安、演员等），教授他们一套完整的交易规则。这些人被称为"**海龟**"（Turtles）。

**结果**：在随后的 4 年里，海龟们平均每年获得 **80%** 的回报率，证明了 Dennis 的观点是正确的。

### 核心规则

海龟交易法是一个**完整的交易系统**，包含以下核心组件：

#### 1. 入场规则 — 唐奇安通道突破

**唐奇安通道（Donchian Channel）**：

**\beginaligned
\text上轨 &= max(High_(t-1), High_(t-2), ..., High_(t-n)) 

\text下轨 &= min(Low_(t-1), Low_(t-2), ..., Low_(t-n))
\endaligned**

| 系统 | 入场条件 | 出场条件 | 适用 |
|------|---------|---------|------|
| **系统一（短期）** | 突破20日最高价做多 | 跌破10日最低价平仓 | 短期趋势 |
| **系统二（长期）** | 突破55日最高价做多 | 跌破20日最低价平仓 | 长期趋势 |

**信号规则**：
- 当价格突破过去20天的最高价时 → **买入**
- 当价格跌破过去20天的最低价时 → **做空**（如果支持做空）
- 上一次突破信号盈利时，跳过下一次信号（避免过度交易）

#### 2. 仓位管理 — ATR 仓位控制

海龟交易法使用 **ATR（平均真实波幅）** 来决定仓位大小，这是其最精妙的设计之一。

**ATR（Average True Range）计算**：

**TR = max\big(H_t - L_t, |H_t - C_(t-1)|, |L_t - C_(t-1)|\big)**

**ATR_n = [1 / n]∑_(i=1)^(n) TR_i**

**单位仓位计算**：

**\textUnit = [ (账户总资金 × 1%) / (ATR × 每手乘数) ]**

**解释**：每一个单位的仓位，在价格波动 1 个 ATR 时，账户浮动恰好是总资金的 1%。

**示例**：
- 账户总资金：100万元
- 某股票ATR = 2元（即该股票平均每天波动2元）
- 每手 = 100股
- Unit = 1,000,000 × 1% / (2 × 100) = **50手 = 5000股**

#### 3. 金字塔加仓

当价格朝有利方向移动时，**分批加仓**：

| 加仓时机 | 条件 | 最大仓位 |
|---------|------|---------|
| 第1次建仓 | 突破信号出现 | 1个单位 |
| 第2次加仓 | 价格在建仓价基础上上涨 0.5 × ATR | 2个单位 |
| 第3次加仓 | 价格在第2次加仓基础上再涨 0.5 × ATR | 3个单位 |
| 第4次加仓 | 价格在第3次加仓基础上再涨 0.5 × ATR | 4个单位（最大） |

#### 4. 止损规则

- **单笔止损**：每个单位的止损为 **2 × ATR**（即最大亏损 = 总资金的 2%）
- **加仓后止损调整**：每次加仓后，将所有仓位的止损位统一调整到最新一次加仓价 - 2×ATR

#### 5. 风险控制

| 风险维度 | 限制 |
|---------|------|
| 单一市场 | 最多 4 个单位 |
| 高度相关市场 | 最多 6 个单位 |
| 单一方向（多/空） | 最多 10 个单位 |
| 总仓位 | 最多 12 个单位 |

### Python 伪代码框架

```python
class TurtleTrading:
    """海龟交易法核心框架"""

    def __init__(self, capital, risk_pct=0.01, atr_period=20,
                 entry_period=20, exit_period=10):
        self.capital = capital
        self.risk_pct = risk_pct
        self.atr_period = atr_period
        self.entry_period = entry_period
        self.exit_period = exit_period

    def calculate_atr(self, df):
        """计算ATR"""
        high_low = df['high'] - df['low']
        high_close = (df['high'] - df['close'].shift(1)).abs()
        low_close = (df['low'] - df['close'].shift(1)).abs()
        tr = pd.concat([high_low, high_close, low_close], axis=1).max(axis=1)
        return tr.rolling(self.atr_period).mean()

    def calculate_unit(self, atr, lot_size=100):
        """计算单位仓位"""
        return int(self.capital * self.risk_pct / (atr * lot_size))

    def generate_signals(self, df):
        """生成交易信号"""
        df = df.copy()
        df['atr'] = self.calculate_atr(df)
        df['upper'] = df['high'].rolling(self.entry_period).max().shift(1)
        df['lower'] = df['low'].rolling(self.entry_period).min().shift(1)
        df['exit_low'] = df['low'].rolling(self.exit_period).min().shift(1)

        # 突破上轨 → 做多
        df['long_entry'] = df['high'] > df['upper']
        # 跌破出场下轨 → 平仓
        df['long_exit'] = df['low'] < df['exit_low']

        return df
```

## 多因子模型

### 📖 理论基础：Fama-French 模型

多因子模型是学术界和业界最重要的量化框架之一。

#### 单因子模型（CAPM）

**E[R_i] - R_f = β_i · (E[R_m] - R_f)**

- R_i：股票 i 的收益率
- R_f：无风险利率
- R_m：市场收益率
- β_i：股票对市场的敏感度

CAPM认为，只有**市场风险**（Beta）一个因子能解释股票的超额收益。

#### Fama-French 三因子模型（1993）

**R_i - R_f = α_i + β_1(R_m - R_f) + β_2 · SMB + β_3 · HML + ε_i**

| 因子 | 名称 | 含义 |
|------|------|------|
| R_m - R_f | **市场因子** | 市场整体的风险溢价 |
| SMB | **规模因子**（Small Minus Big） | 小盘股相对大盘股的超额收益 |
| HML | **价值因子**（High Minus Low） | 高账面市值比相对低账面市值比的超额收益 |

#### Fama-French 五因子模型（2015）

在三因子基础上增加了：

| 因子 | 名称 | 含义 |
|------|------|------|
| RMW | **盈利因子**（Robust Minus Weak） | 高盈利公司相对低盈利公司的超额收益 |
| CMA | **投资因子**（Conservative Minus Aggressive） | 低投资公司相对高投资公司的超额收益 |

### 常用因子详解

| 因子类别 | 因子名称 | 代理变量 | 经济逻辑 |
|---------|---------|---------|---------|
| **价值** | 市盈率（PE） | [P / E] | 低估值股票长期跑赢高估值 |
| | 市净率（PB） | [P / B] | 同上 |
| | 股息率 | [D / P] | 高分红公司通常被低估 |
| **动量** | 过去收益率 | R_(t-12, t-1) | 强者恒强 |
| **质量** | ROE | [ 净利润 / 净资产 ] | 高质量公司值得溢价 |
| | 毛利率 | [ 毛利 / 营收 ] | 高毛利反映竞争优势 |
| **规模** | 市值 | 总市值 | 小盘股长期超额收益 |
| **波动率** | 历史波动率 | σ | 低波动股票风险调整后收益更高 |
| **流动性** | 换手率 | [ 成交量 / 总股本 ] | 低换手率股票可能有流动性溢价 |

### 因子选股流程

```
第1步：因子池构建
├── 收集候选因子（50+个常见因子）
├── 清洗和标准化因子数据
└── 去除共线性高的冗余因子

第2步：因子有效性检验
├── IC（信息系数）分析
│   └── IC = corr(因子值, 下期收益率)
│       理想值: |IC| > 0.03, IC_IR > 0.5
├── 分层回测（Quintile Analysis）
│   └── 按因子值分5组，比较各组收益差异
└── 回归分析

第3步：因子合成
├── 等权合成
├── IC加权合成
│   └── 权重 ∝ 过去N期的IC均值
└── 最优化合成

第4步：组合构建
├── 选取综合因子得分最高的Top N只股票
├── 决定权重分配（等权/市值加权/最优化）
└── 定期再平衡（月度/季度）
```

#### IC 和 IC_IR 的含义

**IC = \textCorr(f_t, r_(t+1))**

**IC_(IR) = [ 平均IC / σ_IC ]**

- **IC（信息系数）**：因子值与未来收益率的相关系数。|IC| > 0.03 表示因子有预测能力
- **IC_IR（信息比率）**：IC均值/IC标准差。IC_(IR) > 0.5 表示因子稳定有效

#### Python 因子分析示例

```python
def factor_analysis(df, factor_col, return_col, n_groups=5):
    """
    因子分层回测

    参数:
        df: DataFrame, 包含因子列和收益率列
        factor_col: 因子列名
        return_col: 下期收益率列名
        n_groups: 分组数量
    """
    df = df.copy()

    # 按因子值分组
    df['group'] = pd.qcut(df[factor_col], n_groups, labels=range(1, n_groups + 1))

    # 计算每组的平均收益
    group_returns = df.groupby('group')[return_col].mean()

    # 多空收益
    long_short = group_returns.iloc[-1] - group_returns.iloc[0]

    # IC值
    ic = df[factor_col].corr(df[return_col])

    print(f"因子: {factor_col}")
    print(f"IC: {ic:.4f}")
    print(f"分组平均收益率:")
    for g, r in group_returns.items():
        print(f"  第{g}组: {r:.4%}")
    print(f"多空收益: {long_short:.4%}")

    return group_returns, ic
```

## 网格交易策略

### 📖 原理

网格交易是一种**在震荡市中自动低买高卖**的策略。

核心思想：
1. 设定一个价格区间
2. 在区间内等距设置多个价格网格
3. 价格每下跌一个网格，买入一份
4. 价格每上涨一个网格，卖出一份

```
价格 ↑
─────── 115 ─── 卖出 ↑
─────── 110 ─── 卖出 ↑
─────── 105 ─── 卖出 ↑
═══════ 100 ═══ 基准价格
─────── 95  ─── 买入 ↓
─────── 90  ─── 买入 ↓
─────── 85  ─── 买入 ↓
价格 ↓
```

### 适用场景

| ✅ 适用 | ❌ 不适用 |
|--------|----------|
| 震荡市（价格在区间内波动） | 单边趋势市（持续上涨或下跌） |
| 波动率适中的标的 | 波动率极低的标的（收益太少） |
| 有明确支撑/阻力位的标的 | 可能退市或暴跌的标的 |

### 网格参数设计

| 参数 | 说明 | 建议值 |
|------|------|-------|
| **网格区间** | 上下限范围 | 基于历史波动范围或支撑/阻力位 |
| **网格数量** | 区间内的网格条数 | 10~30 条 |
| **网格间距** | 相邻网格的价格差 | 1%~5%（视波动率） |
| **每格资金** | 每个网格的交易金额 | 总资金 / 网格数量 |
| **网格类型** | 等差网格 vs 等比网格 | 等比网格更合理 |

#### 等差网格 vs 等比网格

| 类型 | 计算方式 | 特点 |
|------|---------|------|
| **等差网格** | P_i = P_(base) + i × Δ P | 间距固定，低价区密度大 |
| **等比网格** | P_i = P_(base) × (1 + r)^i | 比例固定，更符合金融逻辑 |

**推荐使用等比网格**，因为股票涨跌是按百分比计算的。

#### Python 实现

```python
def create_grid(base_price, num_grids=10, grid_pct=0.02, grid_type='geometric'):
    """
    创建网格价格表

    参数:
        base_price: 基准价格
        num_grids: 上/下各设置的网格数
        grid_pct: 网格间距百分比
        grid_type: 'arithmetic'（等差）或 'geometric'（等比）
    """
    grids = []

    for i in range(-num_grids, num_grids + 1):
        if grid_type == 'geometric':
            price = base_price * (1 + grid_pct) ** i
        else:
            price = base_price + i * base_price * grid_pct

        action = '买入' if i < 0 else ('卖出' if i > 0 else '基准')
        grids.append({'level': i, 'price': round(price, 2), 'action': action})

    return pd.DataFrame(grids)

# 示例
grid_table = create_grid(base_price=100, num_grids=5, grid_pct=0.03)
print(grid_table)
"""
   level   price action
0     -5   86.26   买入
1     -4   88.85   买入
2     -3   91.51   买入
3     -2   94.26   买入
4     -1   97.09   买入
5      0  100.00   基准
6      1  103.00   卖出
7      2  106.09   卖出
8      3  109.27   卖出
9      4  112.55   卖出
10     5  115.93   卖出
"""
```

### ⚠️ 网格交易的风险

1. **单边下跌**：价格持续跌破所有网格，所有买入单亏损
2. **资金利用率低**：需要预留大量资金等待买入
3. **选错标的**：如果标的趋势性太强，网格策略会亏损

## 策略评估指标

衡量一个量化策略的好坏，不能只看收益率。以下是一套完整的评估指标体系：

### 📊 核心指标一览

| 指标 | 公式 | 理想值 | 含义 |
|------|------|-------|------|
| **年化收益率** | (1 + R_(total))^(252/N) - 1 | > 15% | 策略的盈利能力 |
| **夏普比率** | [R_p - R_f / σ_p] | > 1.0 | 每承受一单位风险获得的超额收益 |
| **最大回撤** | max\limits_(t)[Peak_t - Trough_t / Peak_t] | < 20% | 最坏情况下的亏损幅度 |
| **胜率** | [ 盈利次数 / 总交易次数 ] | > 50% | 交易的正确率 |
| **盈亏比** | [ 平均盈利 / 平均亏损 ] | > 1.5 | 赚的时候赚多少 vs 亏的时候亏多少 |
| **Calmar比率** | [ 年化收益率 / 最大回撤 ] | > 1.0 | 收益/风险的另一个衡量 |
| **Sortino比率** | [ (R_p - R_f) / σ_down ] | > 1.5 | 只考虑下行风险的夏普比率 |

### 详细说明

#### 1. 年化收益率

**R_(annual) = (1 + R_(total))^([252 / N]) - 1**

其中 N 是回测天数，252 是一年的交易日数。

#### 2. 夏普比率（Sharpe Ratio）

**S = [E[R_p - R_f] / σ_p] ≈ [ (平均R_p - R_f) / σ_p ] × √252**

- S > 1：良好
- S > 2：优秀
- S > 3：卓越（可能存在过拟合嫌疑）

#### 3. 最大回撤（Maximum Drawdown）

**MDD = max_(t \in [0,T]) [Peak_t - Value_t / Peak_t]**

最大回撤衡量的是"从最高点跌到最低点"的最大幅度，代表了投资者可能经历的最大痛苦。

#### 4. 胜率与盈亏比的关系

一个有正期望值的策略，不需要同时有高胜率和高盈亏比，但需要它们的组合满足：

**E[收益] = \text胜率 × \text平均盈利 - (1 - \text胜率) × \text平均亏损 > 0**

即：

**\text盈亏比 > [ (1 - 胜率) / 胜率 ]**

| 胜率 | 所需最低盈亏比 | 策略类型 |
|------|--------------|---------|
| 30% | > 2.33 | 趋势跟随（低胜率、高盈亏比） |
| 50% | > 1.00 | 平衡型 |
| 70% | > 0.43 | 均值回归（高胜率、低盈亏比） |

#### 5. Calmar 比率

**Calmar = [ 年化收益率 / |最大回撤| ]**

- Calmar > 1：可接受
- Calmar > 2：优秀
- Calmar > 3：卓越

### 评估指标 Python 实现

```python
def calculate_metrics(returns, risk_free_rate=0.03):
    """
    计算策略评估指标

    参数:
        returns: Series, 日收益率序列
        risk_free_rate: 年化无风险利率

    返回:
        dict, 各项评估指标
    """
    # 年化收益率
    total_return = (1 + returns).prod() - 1
    n_days = len(returns)
    annual_return = (1 + total_return) ** (252 / n_days) - 1

    # 年化波动率
    annual_vol = returns.std() * np.sqrt(252)

    # 夏普比率
    daily_rf = (1 + risk_free_rate) ** (1/252) - 1
    sharpe = (returns.mean() - daily_rf) / returns.std() * np.sqrt(252)

    # 最大回撤
    cum_returns = (1 + returns).cumprod()
    peak = cum_returns.cummax()
    drawdown = (cum_returns - peak) / peak
    max_drawdown = drawdown.min()

    # Calmar比率
    calmar = annual_return / abs(max_drawdown) if max_drawdown != 0 else np.inf

    # Sortino比率
    downside_returns = returns[returns < 0]
    downside_vol = downside_returns.std() * np.sqrt(252)
    sortino = (annual_return - risk_free_rate) / downside_vol if downside_vol > 0 else np.inf

    # 胜率
    win_rate = (returns > 0).sum() / len(returns)

    # 盈亏比
    avg_win = returns[returns > 0].mean() if (returns > 0).any() else 0
    avg_loss = abs(returns[returns < 0].mean()) if (returns < 0).any() else 0
    profit_loss_ratio = avg_win / avg_loss if avg_loss > 0 else np.inf

    return {
        '总收益率': f'{total_return:.2%}',
        '年化收益率': f'{annual_return:.2%}',
        '年化波动率': f'{annual_vol:.2%}',
        '夏普比率': f'{sharpe:.2f}',
        '最大回撤': f'{max_drawdown:.2%}',
        'Calmar比率': f'{calmar:.2f}',
        'Sortino比率': f'{sortino:.2f}',
        '胜率': f'{win_rate:.2%}',
        '盈亏比': f'{profit_loss_ratio:.2f}'
    }
```

## 回测陷阱总结

> ⚠️ **"在回测中赚钱很容易，在实盘中赚钱很难。"**

### 🕳️ 陷阱一：过拟合（Overfitting）

**定义**：策略在历史数据上表现完美，但在未来数据上表现很差。

**类比**：就像一个学生只会做过的题目，换了新题就不会。

**识别方法**：
- 参数数量过多（> 5个自由参数就要警惕）
- 回测夏普比率 > 3（过于完美，可能是过拟合）
- 策略逻辑无法用简单的经济学原理解释

**解决方法**：

| 方法 | 说明 |
|------|------|
| **样本外测试** | 将数据分为训练集（70%）和测试集（30%），在测试集上验证 |
| **交叉验证** | 使用Walk-Forward Analysis（滚动前进分析） |
| **减少参数** | 参数越少越好，"如果你不能用3个以内的参数描述策略，可能太复杂了" |
| **多市场测试** | 在不同市场、不同时间段验证策略的普适性 |
| **经济逻辑** | 确保策略有合理的经济学解释，不是纯粹的数据挖掘 |

```
过拟合示意图:

训练集表现     │  ████████████████████ 极好
测试集表现     │  ████████             一般
实盘表现       │  ████                 差

正常策略:
训练集表现     │  ██████████████       良好
测试集表现     │  ████████████         良好
实盘表现       │  ██████████           还行
```

### 🕳️ 陷阱二：未来函数（Look-Ahead Bias）

**定义**：在回测中使用了"未来才能知道"的信息。

**常见错误**：

| 错误 | 正确做法 |
|------|---------|
| 用当天收盘价决定当天是否交易 | 用前一天的数据生成今天的信号 |
| 用全样本数据计算的指标 | 只用截止到当前时点的数据 |
| 使用后复权价格 | 使用前复权或在回测中实时复权 |
| 用尚未发布的财报数据 | 考虑财报发布的实际延迟 |
| 用当天涨停价买入 | 涨停时可能无法买入 |

### 🕳️ 陷阱三：幸存者偏差（Survivorship Bias）

**定义**：只分析"幸存下来"的样本，忽略了已经"死亡"的样本。

**在量化中的体现**：
- 只用当前仍在上市的股票回测 → 忽略了已退市的股票（通常是因为表现差）
- 只看成功的对冲基金的业绩 → 忽略了已关闭的失败基金

**解决方法**：
- 使用**全样本数据**（包含退市股票）
- 数据提供商通常会标注是否包含退市股票

### 🕳️ 陷阱四：忽略交易成本

**定义**：回测时不考虑实际交易中的各种成本。

**\text实际收益 = \text理论收益 - \text佣金 - \text印花税 - \text滑点 - \text冲击成本**

**各类成本估算（A股）**：

| 成本项 | 估算 | 说明 |
|-------|------|------|
| 佣金 | 万分之1.5~3（双边） | 与券商协商 |
| 印花税 | 千分之1（卖出） | 固定，政策可能调整 |
| 滑点 | 万分之1~5 | 视流动性而定 |
| 冲击成本 | 与资金量/成交量比值相关 | 大资金影响大 |

**建议**：回测时至少设置**单边千分之1.5**的总交易成本（包含佣金+滑点）。

### 🕳️ 陷阱五：忽视市场微观结构

| 问题 | 说明 |
|------|------|
| **涨跌停限制** | A股涨停时可能无法买入，跌停时可能无法卖出 |
| **停牌** | 停牌期间无法交易，复牌后可能大幅波动 |
| **最小交易单位** | A股最少100股（1手），小资金可能无法按比例分配 |
| **T+1限制** | A股当天买入不能当天卖出 |
| **集合竞价** | 开盘/收盘价格的形成机制不同于连续竞价 |

### 📋 回测检查清单

在将策略投入实盘前，请逐项检查：

- [ ] 策略是否在样本外数据上也有效？
- [ ] 策略是否在不同市场环境下（牛市/熊市/震荡市）都有正收益？
- [ ] 是否充分考虑了交易成本（佣金+滑点+冲击成本）？
- [ ] 是否使用了包含退市股票的全样本数据？
- [ ] 策略中是否存在未来函数？
- [ ] 策略参数是否足够简洁（< 5个核心参数）？
- [ ] 策略是否有合理的经济学/金融学解释？
- [ ] 最大回撤是否在可接受范围内？
- [ ] 策略容量是否足够（考虑你的资金规模）？
- [ ] 是否进行了压力测试（极端市场情况下的表现）？
