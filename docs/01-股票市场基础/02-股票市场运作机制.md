# 股票市场运作机制 — 交易是如何发生的

> 本章将系统讲解中国股票市场的运作机制，从一级市场的股票发行到二级市场的交易撮合，
> 从交易所的架构到清算交收的全流程，帮助你理解"一笔交易是如何完成的"。

---

## 1. 一级市场 vs 二级市场

股票市场按照交易阶段可以划分为**一级市场（Primary Market）**和**二级市场（Secondary Market）**。
理解二者的区别是认识整个市场运作的起点。

### 1.1 核心概念

- **一级市场**：也称"发行市场"，是公司首次向公众发行股票（IPO）或进行增发（SEO）的市场。
  投资者直接从发行人手中购买股票，资金流入上市公司。
- **二级市场**：也称"流通市场"或"交易市场"，是已发行股票在投资者之间买卖的市场。
  资金在投资者之间流转，与上市公司无直接关系。

### 1.2 详细对比

| 对比维度       | 一级市场（发行市场）                       | 二级市场（流通市场）                         |
| -------------- | ------------------------------------------ | -------------------------------------------- |
| **定义**       | 企业首次公开发行或增发股票的市场           | 已上市股票在投资者之间买卖流通的市场         |
| **核心功能**   | 融资功能——企业募集资金                     | 流通功能——提供流动性，实现价格发现           |
| **资金流向**   | 投资者 → 上市公司                          | 投资者 A → 投资者 B                          |
| **参与者**     | 发行人、承销商（券商）、机构投资者、散户   | 所有开户投资者（散户、机构、外资等）         |
| **定价方式**   | 询价制、竞价制或直接定价                   | 由市场供需决定，实时波动                     |
| **交易场所**   | 通过承销商进行                             | 交易所（上交所、深交所、北交所）             |
| **风险特征**   | 破发风险、锁定期流动性风险                 | 市场波动风险、流动性风险                     |
| **交易频率**   | 一次性（申购后持有）                       | 可反复买卖                                   |
| **监管要求**   | 需通过证监会审核/注册                      | 遵守交易所交易规则                           |
| **对公司影响** | 直接为公司提供资金                         | 间接影响（股价影响再融资能力、公司声誉等）   |

> 💡 **关键理解**：一级市场"创造"股票，二级市场"流通"股票。没有一级市场就没有股票供给，
> 没有二级市场投资者就无法退出，一级市场也将失去吸引力。

## 2. 中国主要交易所介绍

中国大陆目前有三家证券交易所，各有侧重和定位。

### 2.1 三大交易所概览

| 交易所                             | 简称   | 英文缩写 | 成立时间    | 所在地 | 核心定位                           |
| ---------------------------------- | ------ | -------- | ----------- | ------ | ---------------------------------- |
| 上海证券交易所                     | 上交所 | SSE      | 1990年11月  | 上海   | 服务大型蓝筹企业和科技创新企业     |
| 深圳证券交易所                     | 深交所 | SZSE     | 1990年12月  | 深圳   | 服务成长型、创新型中小企业         |
| 北京证券交易所                     | 北交所 | BSE      | 2021年9月   | 北京   | 服务创新型中小企业（原新三板精选层）|

### 2.2 各交易所板块详解

#### 上交所（SSE）

- **主板**：上交所主板主要面向大型成熟企业，以蓝筹股为主，包含大量国有企业、金融机构和大型制造业企业。
- **科创板**：2019年7月正式开板，实行注册制，重点服务于符合国家战略的高新技术产业和战略性新兴产业。
  科创板强调"硬科技"属性，对企业的科技含量有较高要求。

#### 深交所（SZSE）

- **主板**：原深市主板与中小板于2021年合并，面向相对成熟的大中型企业。
- **创业板**：2009年10月开板，2020年实行注册制改革。主要面向成长型创新创业企业，
  对企业的成长性和创新能力有较高要求。

#### 北交所（BSE）

- **北交所**：由新三板精选层平移设立，服务创新型中小企业。
  北交所的特点是上市门槛相对较低，为中小企业提供了直接融资的渠道。
  上市公司需先在新三板挂牌满12个月。

## 3. 股票上市流程（IPO全流程）

一家企业从决定上市到最终挂牌交易，需要经历多个阶段，通常耗时1-3年。

### 3.1 IPO全流程

```
┌─────────────┐
│ 第一阶段：   │
│ 企业改制     │ ──→ 有限责任公司改制为股份有限公司
│ (3-6个月)    │     完成资产重组、股权结构梳理
└──────┬──────┘
       ▼
┌─────────────┐
│ 第二阶段：   │
│ 辅导期       │ ──→ 选聘保荐机构（券商）和律所、会所
│ (6-12个月)   │     完成辅导备案，接受证监局验收
└──────┬──────┘
       ▼
┌─────────────┐
│ 第三阶段：   │
│ 申报材料     │ ──→ 制作招股说明书、财务审计报告等
│ (2-3个月)    │     向交易所提交上市申请
└──────┬──────┘
       ▼
┌─────────────┐
│ 第四阶段：   │
│ 审核问询     │ ──→ 交易所审核中心审核（注册制下）
│ (3-6个月)    │     经历多轮问询函回复
│              │     上市委员会审议
└──────┬──────┘
       ▼
┌─────────────┐
│ 第五阶段：   │
│ 证监会注册   │ ──→ 交易所审核通过后报证监会注册
│ (约20个工作日)│     证监会在规定时限内作出是否注册的决定
└──────┬──────┘
       ▼
┌─────────────┐
│ 第六阶段：   │
│ 路演与询价   │ ──→ 发行人与保荐机构进行网上/网下路演
│ (1-2周)      │     向机构投资者询价确定发行价格
│              │     公布发行价格和发行数量
└──────┬──────┘
       ▼
┌─────────────┐
│ 第七阶段：   │
│ 发行与申购   │ ──→ 网上申购（散户打新）
│ (约1周)      │     网下配售（机构投资者）
│              │     中签公布与缴款
└──────┬──────┘
       ▼
┌─────────────┐
│ 第八阶段：   │
│ 挂牌上市     │ ──→ 在交易所正式挂牌交易
│              │     新股上市首日不设涨跌幅限制（注册制板块前5日不设）
└─────────────┘
```

### 3.2 关键参与方

| 参与方           | 职责                                             |
| ---------------- | ------------------------------------------------ |
| **发行人**       | 拟上市公司，提供真实完整的信息披露               |
| **保荐机构**     | 通常由券商投行部门担任，全程辅导和保荐           |
| **会计师事务所** | 负责财务审计，出具审计报告                       |
| **律师事务所**   | 出具法律意见书，确保合法合规                     |
| **交易所**       | 注册制下的审核主体                               |
| **证监会**       | 最终注册机关，负责宏观审慎监管                   |
| **中登公司**     | 负责新股的登记、托管和结算                       |

### 3.3 注册制与核准制的区别

自2023年2月全面注册制实施以来，A股市场已全面采用注册制。

| 对比维度   | 核准制（已退出历史舞台）       | 注册制（现行）                     |
| ---------- | ------------------------------ | ---------------------------------- |
| 审核主体   | 证监会发审委                   | 交易所审核 + 证监会注册            |
| 审核重点   | 实质性审核（盈利能力判断）     | 信息披露为核心                     |
| 审核效率   | 排队时间长，通常1-3年          | 审核周期明显缩短                   |
| 上市标准   | 统一盈利门槛                   | 多元包容的上市条件                 |
| 定价方式   | 窗口指导（23倍市盈率限制）     | 市场化询价                         |

## 4. 交易撮合机制详解

交易撮合是股票交易的核心环节。中国A股市场采用**集合竞价**和**连续竞价**两种方式。

### 4.1 交易时间安排

| 时间段            | 交易方式       | 适用范围           |
| ----------------- | -------------- | ------------------ |
| 9:15 — 9:25       | 开盘集合竞价   | 所有板块           |
| 9:25 — 9:30       | 静默期         | 不接受撤单         |
| 9:30 — 11:30      | 连续竞价       | 所有板块           |
| 11:30 — 13:00     | 午间休市       | —                  |
| 13:00 — 14:57     | 连续竞价       | 所有板块           |
| 14:57 — 15:00     | 尾盘集合竞价   | 所有板块           |

### 4.2 集合竞价详解

集合竞价是在规定时间内，将所有买卖申报集中一次性撮合成交的方式。
成交价格的确定原则是：**使成交量最大化的价格。**

#### 开盘集合竞价三个阶段

**第一阶段：9:15 — 9:20（自由申报期）**
- 可以申报买入和卖出
- 可以撤销申报
- 此阶段可能出现虚假申报（大单挂出后立即撤单），投资者需谨慎判断

**第二阶段：9:20 — 9:25（锁定申报期）**
- 可以申报买入和卖出
- **不可以撤销申报**
- 这是真实的竞价阶段，此时的挂单反映真实交易意愿
- 9:25确定开盘价

**第三阶段：9:25 — 9:30（静默期/接单期）**
- 交易系统接受申报但不做处理
- **不可以撤单**
- 所有申报在9:30连续竞价开始时按时间优先顺序进入撮合

#### 尾盘集合竞价（14:57 — 15:00）

- 与开盘集合竞价的9:20-9:25阶段规则类似
- 可以申报，但**不可以撤单**
- 15:00确定收盘价
- 尾盘集合竞价的引入是为了防止尾盘操纵收盘价

### 4.3 集合竞价撮合示例

假设某股票在9:20-9:25期间收到以下委托：

**买入委托：**

| 序号 | 买入价格（元） | 买入数量（手） |
| ---- | -------------- | -------------- |
| B1   | 10.05          | 200            |
| B2   | 10.03          | 300            |
| B3   | 10.00          | 500            |
| B4   | 9.98           | 400            |

**卖出委托：**

| 序号 | 卖出价格（元） | 卖出数量（手） |
| ---- | -------------- | -------------- |
| S1   | 9.96           | 100            |
| S2   | 9.98           | 200            |
| S3   | 10.00          | 400            |
| S4   | 10.03          | 300            |

**撮合过程分析：**

在每一个候选价位上，统计可成交的最大数量：

| 候选价格 | 买入累积量（≥该价格） | 卖出累积量（≤该价格） | 可成交量（取较小值） |
| -------- | --------------------- | --------------------- | -------------------- |
| 10.05    | 200                   | 1000                  | 200                  |
| 10.03    | 500                   | 700                   | 500                  |
| **10.00**| **1000**              | **700**               | **700** ✅           |
| 9.98     | 1400                  | 300                   | 300                  |
| 9.96     | 1400                  | 100                   | 100                  |

**结论**：**10.00元**是使成交量最大的价格（700手），因此开盘价确定为**10.00元**。

在10.00元的价格下：
- 买入价≥10.00元的委托（B1、B2、B3共1000手）全部或部分成交
- 卖出价≤10.00元的委托（S1、S2、S3共700手）全部成交
- 实际成交700手，买入方剩余300手未成交部分进入连续竞价

### 4.4 连续竞价详解

连续竞价是在集合竞价结束后的交易时间内，对买卖申报逐笔连续撮合的方式。

**核心原则：价格优先、时间优先**

1. **价格优先**：买入申报中，价格最高的优先；卖出申报中，价格最低的优先
2. **时间优先**：在价格相同的情况下，先提交的申报优先成交

**成交价格确定规则：**

- 最高买入价≥最低卖出价时，取先提交方的价格为成交价
- 如果买入申报先提交，以买入价成交
- 如果卖出申报先提交，以卖出价成交

**连续竞价撮合示例：**

假设当前订单簿（Order Book）状态如下：

| 买入队列             | 卖出队列             |
| -------------------- | -------------------- |
| 10.00元 × 300手      | 10.02元 × 200手      |
| 9.98元 × 500手       | 10.05元 × 400手      |
| 9.95元 × 200手       | 10.08元 × 100手      |

此时一笔新的买入委托进入：**以10.05元买入350手**

撮合过程：
1. 先与卖一（10.02元 × 200手）成交200手，成交价10.02元
2. 再与卖二（10.05元 × 150手）成交150手，成交价10.05元
3. 共成交350手，卖二剩余250手继续挂在卖一位置（10.05元 × 250手）

## 5. 订单类型

### 5.1 限价委托

限价委托（Limit Order）是指投资者指定一个价格，买入时只能以该价格或更低价格成交，
卖出时只能以该价格或更高价格成交。

**特点：**
- 可以控制成交价格
- 不保证一定成交
- 适合对价格敏感的交易

### 5.2 市价委托

市价委托（Market Order）是指不指定具体价格，以当前市场最优价格尽快成交的委托方式。
上交所和深交所提供的市价委托类型略有不同。

#### 五种市价委托类型

| 类型                         | 说明                                                                 | 适用交易所   |
| ---------------------------- | -------------------------------------------------------------------- | ------------ |
| **对手方最优价格委托**       | 以对手方（对方）最优价格为成交价，未成交部分自动撤销                 | 上交所、深交所 |
| **本方最优价格委托**         | 以本方（己方）最优价格为成交价，未成交部分自动撤销                   | 上交所、深交所 |
| **最优五档即时成交剩余撤销** | 在对手方最优五个价位内依次成交，未成交部分自动撤销                   | 上交所、深交所 |
| **最优五档即时成交剩余转限价** | 在对手方最优五个价位内依次成交，未成交部分转为限价委托               | 上交所       |
| **全额成交或撤销（FOK）**   | 如果不能全部成交，则全部撤销                                         | 深交所       |

### 5.3 限价委托 vs 市价委托对比

| 对比维度     | 限价委托                     | 市价委托                         |
| ------------ | ---------------------------- | -------------------------------- |
| 价格控制     | ✅ 可精确控制                | ❌ 无法控制，可能滑点            |
| 成交速度     | ❌ 不保证立即成交            | ✅ 优先成交                      |
| 适用场景     | 震荡行情、价格敏感交易       | 快速行情、需要确保成交的场景     |
| 风险         | 可能错过行情                 | 可能产生较大滑点成本             |
| 集合竞价可用 | ✅ 可使用                    | ❌ 不可使用（仅连续竞价可用）    |

> ⚠️ **注意**：市价委托仅在连续竞价阶段有效，集合竞价阶段只接受限价委托。

## 6. 清算与交收流程

### 6.1 T+1交收制度

中国A股市场实行**T+1交收制度**：

- **T日**：交易日，即买卖成交当天
- **T+1日**：交收日，完成资金和证券的最终交割

**具体含义：**
- 投资者T日买入的股票，T日不能卖出，需等到T+1日才能卖出（"T+1回转交易限制"）
- 资金交收在T+1日完成
- T日卖出股票获得的资金当天可用于购买股票（可用），但不可提现（不可取），T+1日方可提取

### 6.2 中国证券登记结算有限责任公司（中登公司/中国结算）

中登公司是中国资本市场的**核心金融基础设施**，主要职责包括：

| 职能             | 说明                                                     |
| ---------------- | -------------------------------------------------------- |
| **证券登记**     | 记录证券的持有人信息，维护股东名册                       |
| **证券存管**     | 集中存管所有已上市证券，实现无纸化                       |
| **清算**         | 计算每个参与方在交易日的应收应付净额（多边净额清算）     |
| **交收**         | 在T+1日完成证券和资金的最终交割                         |
| **新股登记**     | IPO新股的初始登记                                       |
| **公司行为服务** | 代理分红派息、配股、送转股等公司行为                     |

### 6.3 资金交收 vs 证券交收

| 交收类型     | 流程说明                                                           |
| ------------ | ------------------------------------------------------------------ |
| **证券交收** | T日成交后，中登公司在T日日终完成证券的簿记划转（证券实时到账）     |
| **资金交收** | T日成交后，中登公司在T+1日与各结算参与人完成资金的净额交收         |

**资金清算流程：**

```
T日交易完成
     ▼
T日日终：中登公司计算各结算参与人（券商）的净应收/净应付
     ▼
T+1日：
  - 净应付方（券商A）：在规定时间前将资金划入中登公司指定账户
  - 净应收方（券商B）：中登公司将资金划入其账户
     ▼
交收完成
```

> 📌 **DVP机制**：中登公司正在推行"货银对付"（Delivery versus Payment, DVP）机制，
> 即证券交收和资金交收同步进行，以降低交收风险。

## 7. 交易参与者

A股市场的参与者可以按类型分为以下几类：

### 7.1 各类投资者一览

| 参与者类型         | 说明                                                   | 特点                                       |
| ------------------ | ------------------------------------------------------ | ------------------------------------------ |
| **散户（个人投资者）** | 持有A股账户的自然人投资者                             | 数量庞大（超2亿户），交易占比高，信息劣势   |
| **公募基金**       | 面向公众募集资金，由基金公司专业管理                   | 信息披露透明，投资策略受监管约束             |
| **私募基金**       | 面向合格投资者非公开募集（100万元起投）                | 策略灵活，杠杆运用多，信披要求相对宽松       |
| **保险资金**       | 保险公司运用保费收入进行投资                           | 资金量大、期限长，偏好分红稳定的蓝筹股       |
| **社保基金**       | 全国社会保障基金，由社保基金理事会管理                 | 长期投资、注重安全性，被视为"国家队"         |
| **企业年金/职业年金** | 企事业单位的补充养老金                              | 类似社保基金，追求长期稳健收益               |
| **QFII/RQFII**    | 合格境外机构投资者/人民币合格境外机构投资者           | 外资进入A股的主要通道之一                   |
| **沪深港通北向资金** | 通过港股通机制进入A股的境外资金（俗称"北向资金"）    | 外资风向标，市场关注度高                     |
| **做市商**         | 北交所实行做市商制度，部分券商为指定做市商             | 提供流动性，维护市场稳定                     |
| **券商自营**       | 证券公司用自有资金进行交易                             | 专业性强，受净资本约束                       |

### 7.2 市场结构特征

中国A股市场的显著特征是**散户占比高**：
- 散户贡献了约60%-70%的交易量
- 但散户持有的市值占比仅约25%-30%
- 机构化趋势持续推进，公募基金和外资占比逐年提升

## 8. 交易成本详解

### 8.1 各项费用明细

| 费用项目     | 收费标准                         | 收取方     | 备注                                   |
| ------------ | -------------------------------- | ---------- | -------------------------------------- |
| **券商佣金** | 不超过成交金额的3‰，普遍为万2.5~万1 | 证券公司   | 买卖双向收取，最低5元/笔               |
| **印花税**   | 成交金额的0.5‰（千分之零点五）   | 国家税务   | **仅卖出时收取**（2023年8月下调）      |
| **过户费**   | 成交金额的0.01‰（十万分之一）    | 中登公司   | 买卖双向收取                           |
| **经手费**   | 成交金额的0.00341%（上交所A股）  | 交易所     | 已包含在券商佣金中                     |
| **证管费**   | 成交金额的0.002%                 | 证监会     | 已包含在券商佣金中                     |

> 📌 **说明**：经手费和证管费统称"规费"，通常已包含在券商佣金中，不另行收取。
> 部分券商会标注"佣金中是否含规费"，影响实际费率对比。

### 8.2 交易成本计算示例

**场景**：投资者以10元/股的价格买入10000股某上交所股票（佣金费率万2.5），
随后以12元/股的价格全部卖出。

**买入成本计算：**

| 费用项目 | 计算公式                           | 金额（元） |
| -------- | ---------------------------------- | ---------- |
| 成交金额 | 10元 × 10000股                     | 100,000    |
| 券商佣金 | 100,000 × 0.025% = 25元           | 25.00      |
| 印花税   | 买入不收                           | 0          |
| 过户费   | 100,000 × 0.001% = 1元            | 1.00       |
| **合计** |                                    | **26.00**  |

**卖出成本计算：**

| 费用项目 | 计算公式                           | 金额（元） |
| -------- | ---------------------------------- | ---------- |
| 成交金额 | 12元 × 10000股                     | 120,000    |
| 券商佣金 | 120,000 × 0.025% = 30元           | 30.00      |
| 印花税   | 120,000 × 0.05% = 60元            | 60.00      |
| 过户费   | 120,000 × 0.001% = 1.2元          | 1.20       |
| **合计** |                                    | **91.20**  |

**盈亏汇总：**

```
股票盈利 = 卖出成交金额 - 买入成交金额 = 120,000 - 100,000 = 20,000 元
总交易成本 = 买入费用 + 卖出费用 = 26.00 + 91.20 = 117.20 元
净利润 = 20,000 - 117.20 = 19,882.80 元
交易成本占盈利比 = 117.20 / 20,000 ≈ 0.59%
```

> 💡 **启示**：虽然单次交易成本看似不高，但频繁交易会使成本快速累积。
> 假设年换手率为1000%（即资金周转10次），以万2.5的佣金和总费用约万7计算，
> 年交易成本 = 万7 × 2（买卖双向）× 10次 ≈ 1.4%，这将显著侵蚀收益。

## 9. 开户流程简述

### 9.1 线上开户（主流方式）

目前90%以上的新开户都通过线上完成，流程如下：

**步骤一：选择券商**
- 综合考虑佣金费率、交易软件体验、研究报告质量、线下网点覆盖等因素
- 目前主流互联网券商佣金可低至万1~万1.5

**步骤二：下载券商APP**
- 在手机应用商店下载对应券商的官方APP

**步骤三：在线开户流程**
1. 手机号注册/登录
2. 上传身份证正反面照片
3. 填写个人信息（姓名、地址、职业等）
4. 选择开户营业部
5. 绑定银行卡（三方存管）
6. 进行风险评估问卷
7. 视频见证（与券商客服视频通话验证身份）
8. 设置交易密码和资金密码
9. 提交申请，等待审核（通常1-2个工作日）

**所需材料：**
- 本人有效身份证
- 本人银行借记卡
- 手机（用于接收验证码和视频见证）

### 9.2 线下开户

投资者也可以携带身份证和银行卡到券商营业部现场办理，流程与线上类似，
但需现场填写纸质表格。适合不习惯线上操作的投资者。

### 9.3 特殊权限开通

部分板块和品种需要额外申请开通权限：

| 权限             | 开通条件                                     |
| ---------------- | -------------------------------------------- |
| 科创板交易权限   | 开通前20个交易日日均证券资产≥50万元 + 24个月交易经验 |
| 创业板交易权限   | 开通前20个交易日日均证券资产≥10万元 + 24个月交易经验 |
| 北交所交易权限   | 开通前20个交易日日均证券资产≥50万元 + 24个月交易经验 |
| 融资融券         | 开通前20个交易日日均证券资产≥50万元 + 6个月交易经验   |
| 港股通           | 开通前20个交易日日均证券资产≥50万元                 |

## 10. 本章小结

本章从多个维度系统性地介绍了中国股票市场的运作机制：

| 知识模块       | 核心要点                                                           |
| -------------- | ------------------------------------------------------------------ |
| 一级市场vs二级市场 | 一级市场负责"创造"股票（IPO），二级市场负责"流通"股票         |
| 三大交易所     | 上交所（蓝筹+科创）、深交所（成长+创业）、北交所（创新型中小企业） |
| IPO流程        | 改制→辅导→申报→审核→注册→路演→发行→上市，全面注册制             |
| 交易撮合       | 集合竞价（开盘/尾盘）+ 连续竞价，价格优先、时间优先原则           |
| 订单类型       | 限价委托（可控价格）和市价委托（确保成交）                         |
| 清算交收       | T+1交收制度，中登公司为核心清算交收机构                           |
| 市场参与者     | 散户为主要交易力量，机构化趋势持续推进                             |
| 交易成本       | 佣金+印花税+过户费，频繁交易会累积大量成本                       |
| 开户流程       | 线上开户为主流，特殊板块需额外开通权限                             |
