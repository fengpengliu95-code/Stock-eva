# 交易规则与核心术语词汇表

> 本章系统梳理 A 股市场的核心交易规则与常用术语，帮助你在实战中精准理解盘面语言，避免因规则不清而造成不必要的损失。

---

## 一、交易时间表

A 股市场的交易日为**周一至周五**（法定节假日除外）。每个交易日分为以下几个阶段：

### 1.1 完整交易时间线

| 时间段 | 阶段名称 | 说明 |
|---|---|---|
| **9:15 - 9:20** | 集合竞价（开放期） | 可以**挂单、也可以撤单**。此阶段的报价仅用于撮合参考，不产生真实成交。主力常在此阶段试盘，观察挂单情况。 |
| **9:20 - 9:25** | 集合竞价（封闭期） | 可以**挂单、但不能撤单**。系统在 9:25 按照"最大成交量"原则确定开盘价。⚠️ 新手注意：此阶段挂出的单无法撤回，需谨慎操作。 |
| **9:25 - 9:30** | 集合竞价结果 / 委托暂存期 | 9:25 产生开盘价。9:25-9:30 期间可以接受委托，但不撮合成交，所有委托单进入待成交队列，等待 9:30 连续竞价开始后按**价格优先、时间优先**原则撮合。 |
| **9:30 - 11:30** | 上午连续竞价 | 正式交易时段。按照"价格优先、时间优先"原则实时撮合成交。这是市场最活跃的阶段之一，尤其是 **9:30-10:00** 波动最为剧烈。 |
| **11:30 - 13:00** | 午间休市 | 暂停交易。期间可以委托挂单，但不会撮合。部分券商支持在此期间提交委托。 |
| **13:00 - 14:57** | 下午连续竞价 | 正式交易时段。通常 **14:30** 之后市场活跃度再次提升，尾盘资金动向值得关注。 |
| **14:57 - 15:00** | 尾盘集合竞价 | 与开盘集合竞价类似，可以挂单但**不能撤单**。系统在 15:00 按照最大成交量原则确定**收盘价**。收盘价是当日最重要的价格之一，直接影响次日涨跌停价格的计算。 |
| **15:00 之后** | 收市 / 盘后固定价格交易 | 上交所有盘后固定价格交易（15:05-15:30），以收盘价成交。深交所也已推出类似机制。 |

### 1.2 关键时间节点提示

| 时间点 | 重要事件 |
|---|---|
| 9:15 | 集合竞价开始，可以开始挂单 |
| 9:20 | 进入不可撤单阶段，注意挂单风险 |
| 9:25 | **开盘价确定** |
| 9:30 | 连续竞价正式开始，盘面开始波动 |
| 10:30 | 上午中段，通常波动趋于平缓 |
| 11:30 | 午间休市开始 |
| 13:00 | 下午开盘 |
| 14:57 | 尾盘集合竞价开始，不可撤单 |
| 15:00 | **收盘价确定**，当日交易结束 |

> 💡 **实战提示**：9:25 确定的开盘价与前一日收盘价的差距（即"高开"或"低开"幅度），是判断当日市场情绪的重要信号。

## 二、涨跌停规则详解

涨跌停制度是 A 股市场的重要保护机制，旨在**限制单日过度波动**，保护投资者利益。不同板块的涨跌幅限制不同。

### 2.1 各板块涨跌幅限制一览

| 板块 | 涨跌幅限制 | 适用范围 | 特殊规定 |
|---|---|---|---|
| **主板**（沪市/深市） | **±10%** | 上证主板、深证主板所有股票 | 无特殊例外 |
| **创业板**（300 开头） | **±20%** | 深交所创业板股票 | 新股**上市前 5 个交易日不设涨跌幅限制** |
| **科创板**（688 开头） | **±20%** | 上交所科创板股票 | 新股**上市前 5 个交易日不设涨跌幅限制** |
| **北交所**（8 开头） | **±30%** | 北京证券交易所股票 | 新股**上市首日不设涨跌幅限制** |
| **ST 股票** | **±5%** | 被特别处理的风险警示股票 | 基本面存在重大风险 |
| **\*ST 股票** | **±5%** | 被退市风险警示的股票 | 有退市可能，投资风险极高 |

> ⚠️ **注意**：创业板和科创板的 ±20% 以及北交所的 ±30% 使得这些板块波动更大，适合有一定经验的投资者。新手建议从主板（±10%）开始。

### 2.2 涨跌停价格计算公式

涨跌停价格的计算基于**前一交易日的收盘价**（昨收价）：

```
涨停价 = 昨收价 ×（1 + 涨跌幅限制比例）
跌停价 = 昨收价 ×（1 - 涨跌幅限制比例）
```

**四舍五入规则**：计算结果按照**四舍五入**保留到小数点后两位（即精确到分）。

### 2.3 涨跌停计算示例

#### 示例一：主板股票（±10%）

假设某主板股票昨收价为 **15.80 元**：

| 项目 | 计算过程 | 结果 |
|---|---|---|
| 涨停价 | 15.80 × (1 + 10%) = 15.80 × 1.10 = 17.380 | **17.38 元** |
| 跌停价 | 15.80 × (1 - 10%) = 15.80 × 0.90 = 14.220 | **14.22 元** |
| 当日价格区间 | — | 14.22 ~ 17.38 元 |

#### 示例二：创业板/科创板股票（±20%）

假设某创业板股票昨收价为 **32.50 元**：

| 项目 | 计算过程 | 结果 |
|---|---|---|
| 涨停价 | 32.50 × 1.20 = 39.000 | **39.00 元** |
| 跌停价 | 32.50 × 0.80 = 26.000 | **26.00 元** |
| 当日价格区间 | — | 26.00 ~ 39.00 元 |

#### 示例三：ST 股票（±5%）

假设某 ST 股票昨收价为 **3.26 元**：

| 项目 | 计算过程 | 结果 |
|---|---|---|
| 涨停价 | 3.26 × 1.05 = 3.423 | **3.42 元**（四舍五入） |
| 跌停价 | 3.26 × 0.95 = 3.097 | **3.10 元**（四舍五入） |
| 当日价格区间 | — | 3.10 ~ 3.42 元 |

#### 示例四：北交所股票（±30%）

假设某北交所股票昨收价为 **10.00 元**：

| 项目 | 计算过程 | 结果 |
|---|---|---|
| 涨停价 | 10.00 × 1.30 = 13.000 | **13.00 元** |
| 跌停价 | 10.00 × 0.70 = 7.000 | **7.00 元** |
| 当日价格区间 | — | 7.00 ~ 13.00 元 |

### 2.4 涨跌停相关注意事项

1. **涨停板可以买入吗？** 可以，但涨停时卖盘稀少，通常需要**排队等待**，不一定能买到（"排板"）。
2. **涨停板可以卖出吗？** 可以，且通常能**立即成交**，因为涨停时有大量买单排队。
3. **跌停板可以卖出吗？** 可以，但跌停时买盘极少，可能**无法成交**或只能部分成交。
4. **跌停板可以买入吗？** 可以，且通常能**立即成交**。
5. **一字涨停/一字跌停**：开盘直接封在涨停或跌停价，全天无法交易（"一字板"）。这种情况下，散户几乎不可能买到（涨停）或卖出（跌停）。

## 三、T+1 交易制度详解

### 3.1 什么是 T+1？

T+1 是 A 股市场的交易结算制度，其中：

- **T** = Trade Day（交易日），即**买入当天**
- **+1** = 下一个交易日

**核心规则**：当天买入的股票，**最早要到下一个交易日才能卖出**。

> 举例：周一买入某股票 → 最早周二才能卖出。如果周五买入 → 最早下周一才能卖出（周末不是交易日）。

### 3.2 T+1 vs T+0 对比

| 对比项 | T+1（A 股现行制度） | T+0（港股/美股制度） |
|---|---|---|
| 卖出时间 | 买入后次日才能卖出 | 买入当天即可卖出 |
| 日内交易 | **不允许**（当天买入不能当天卖出） | **允许**（可以日内多次买卖） |
| 风险控制 | 投资者无法当日止损（被"锁仓"一天） | 可以及时止损，灵活性高 |
| 投机性 | 相对较低 | 较高（容易过度交易） |
| 适用市场 | A 股（沪深京） | 港股、美股、期货、期权 |

### 3.3 T+1 制度对交易策略的影响

1. **买入决策更谨慎**：因为当天买入无法卖出，所以买入前必须充分分析，避免冲动交易。
2. **不能日内止损**：如果买入后当天股价大跌，投资者只能"被动持有"到次日，无法当天割肉。这要求投资者在买入前就设定好止损位。
3. **尾盘买入策略**：部分交易者倾向于在 **14:30 之后** 买入，以减少当天价格波动带来的不确定性，并在次日开盘后观察走势。
4. **利好仓位管理**：由于无法当天调仓，投资者需要提前规划好仓位，避免满仓操作带来的被动局面。
5. **做 T 技巧**：虽然当天买入的股票不能卖出，但可以卖出**已有持仓**并在当天重新买入，实现"T+0 效果"（俗称"做 T"）。

> 💡 **做 T 示例**：你昨天持有 1000 股某股票。今天该股早盘冲高，你在高位**卖出 500 股**；午后股价回落，你在低位**买回 500 股**。这样虽然持仓数不变，但降低了持仓成本。这就是"正 T"操作。

### 3.4 资金交收规则

| 项目 | 规则 |
|---|---|
| 股票交割 | T+1（次日交割到账） |
| 资金可用 | T 日卖出股票所得资金**当天可用于买入**其他股票 |
| 资金可取 | T+1（卖出后次日才能从证券账户转出到银行卡） |

## 四、核心术语词汇表

以下按类别整理 A 股市场中最常用的核心术语，共计 **70+ 个**。

### 4.1 价格类术语

| 术语 | 英文/缩写 | 释义 |
|---|---|---|
| **开盘价** | Open Price | 每个交易日集合竞价阶段（9:25）确定的第一个成交价格 |
| **收盘价** | Close Price | 每个交易日尾盘集合竞价（15:00）确定的最后一个成交价格 |
| **最高价** | High Price | 当日所有成交价格中的最高值 |
| **最低价** | Low Price | 当日所有成交价格中的最低值 |
| **昨收价** | Previous Close | 前一个交易日的收盘价，是计算涨跌停价格和涨跌幅的基准 |
| **均价** | Average Price / VWAP | 当日成交总额除以成交总量，反映当日的平均成交成本 |
| **涨停价** | Upper Limit Price | 当日允许的最高交易价格（= 昨收价 × (1 + 涨跌幅限制)） |
| **跌停价** | Lower Limit Price | 当日允许的最低交易价格（= 昨收价 × (1 - 涨跌幅限制)） |
| **前复权价** | Forward Adjusted Price | 以当前价格为基准，向前调整历史价格以消除除权除息的影响。图表更直观，常用于技术分析 |
| **后复权价** | Backward Adjusted Price | 以上市首日价格为基准，向后调整价格以消除除权除息的影响。可以看到真实的累计涨幅 |
| **现价** | Current Price / Last Price | 最新一笔成交的价格 |
| **结算价** | Settlement Price | 用于计算保证金和盈亏的基准价格，主要用于期货市场 |

### 4.2 交易类术语

| 术语 | 英文/缩写 | 释义 |
|---|---|---|
| **买入（做多）** | Buy / Long | 以一定价格购入股票，预期上涨后卖出获利 |
| **卖出** | Sell | 将持有的股票以一定价格出售 |
| **委托（挂单）** | Order / Pending Order | 向券商提交买入或卖出指令，等待系统撮合成交 |
| **成交** | Filled / Executed | 委托单被撮合完成，买卖双方达成交易 |
| **撤单** | Cancel Order | 在委托未成交前，取消已提交的委托指令 |
| **限价委托** | Limit Order | 以指定价格或更优价格委托买卖，不保证成交 |
| **市价委托** | Market Order | 以当前市场最优价格立即成交，保证成交但不保证价格 |
| **集合竞价** | Call Auction | 在特定时间段内（开盘/收盘），汇集所有委托单，按最大成交量原则确定一个统一价格进行撮合 |
| **连续竞价** | Continuous Auction | 在正式交易时段内（9:30-11:30, 13:00-14:57），逐笔实时撮合成交 |
| **大宗交易** | Block Trade | 单笔交易数量或金额达到规定标准的大额交易，通常在收盘后通过专门系统完成，不影响盘中价格 |
| **融资买入** | Margin Buy | 向券商借入资金买入股票（杠杆交易），需要开通融资融券账户 |
| **融券卖出** | Short Sell | 向券商借入股票并卖出，预期下跌后低价买回归还（做空机制） |
| **竞价成交** | Auction Match | 通过集合竞价或连续竞价方式完成的成交 |

### 4.3 仓位类术语

| 术语 | 英文/缩写 | 释义 |
|---|---|---|
| **建仓（开仓）** | Open Position | 首次买入某只股票，建立持仓头寸 |
| **加仓** | Add Position | 对已持有的股票追加买入，增大持仓量 |
| **减仓** | Reduce Position | 卖出部分持有的股票，缩小持仓量 |
| **清仓（平仓）** | Close Position / Liquidate | 将某只股票的全部持仓卖出，完全退出 |
| **满仓** | Full Position | 将所有可用资金全部买入股票，无剩余现金 |
| **半仓** | Half Position | 用约 50% 的资金买入股票，保留一半现金 |
| **空仓** | Empty Position | 不持有任何股票，全部资金为现金状态 |
| **补仓** | Cover / Average Down | 在持有股票下跌后，以更低价格再次买入以**摊低持仓成本** |
| **锁仓** | Lock Position | 在同一品种上同时持有多头和空头头寸，互相对冲锁定利润或亏损（期货中常见） |
| **重仓** | Heavy Position | 将较大比例（通常 70% 以上）的资金集中投入某只或某几只股票 |
| **轻仓** | Light Position | 仅投入较小比例的资金，保持较多现金以防风险 |

### 4.4 趋势类术语

| 术语 | 英文/缩写 | 释义 |
|---|---|---|
| **多头** | Bull / Long | 预期股价上涨的一方，持有看涨观点 |
| **空头** | Bear / Short | 预期股价下跌的一方，持有看跌观点 |
| **牛市** | Bull Market | 股市整体呈持续上涨趋势的市场状态 |
| **熊市** | Bear Market | 股市整体呈持续下跌趋势的市场状态 |
| **震荡市** | Volatile / Range-bound Market | 市场在一定范围内上下波动，无明确方向 |
| **横盘** | Sideways / Consolidation | 股价在一个狭窄区间内波动，既不明显上涨也不明显下跌 |
| **反弹** | Rebound / Bounce | 股价在下跌趋势中出现短暂的上涨回升，通常不改变整体下跌趋势 |
| **反转** | Reversal | 股价趋势发生根本性转变：从上涨转为下跌，或从下跌转为上涨 |
| **回调** | Pullback / Correction | 股价在上涨趋势中出现短暂的下跌调整，通常不改变整体上涨趋势 |
| **盘整** | Consolidation | 股价在经历一段上涨或下跌后，进入窄幅波动的整理阶段 |
| **突破** | Breakout | 股价向上突破某一关键阻力位或重要均线，通常被视为上涨信号 |
| **破位** | Breakdown | 股价向下跌破某一关键支撑位或重要均线，通常被视为下跌信号 |
| **探底** | Test Bottom | 股价下跌到一定程度后开始寻找底部支撑区域 |
| **筑底** | Build Bottom | 股价在底部区域反复震荡整理，形成底部形态 |

### 4.5 数据指标类术语

| 术语 | 英文/缩写 | 释义 | 参考值 / 公式 |
|---|---|---|---|
| **成交量** | Volume (VOL) | 某一时间段内成交的股票总手数（1手=100股） | 量增价涨为健康上涨信号 |
| **成交额** | Turnover Amount | 某一时间段内成交的总金额（元） | 成交额 = Σ (成交价 × 成交量) |
| **换手率** | Turnover Rate | 当日成交量占流通股本的百分比 | 换手率 = 成交量 / 流通股本 × 100%。通常 <3% 为低换手，>10% 为高换手 |
| **量比** | Volume Ratio | 当日每分钟平均成交量与过去5日每分钟平均成交量的比值 | 量比 = 当日实时成交量 / (过去5日平均成交量 / 当日已开盘分钟数)。>1 表示放量，<1 表示缩量 |
| **委比** | Order Ratio | 衡量买卖委托力量对比的指标 | 委比 = (委买手数 - 委卖手数) / (委买手数 + 委卖手数) × 100%。正值表示买方力量强 |
| **内盘** | Inside Volume | 以买入价成交的数量（即卖方主动以较低价卖出） | 内盘大表示卖方积极，看跌信号 |
| **外盘** | Outside Volume | 以卖出价成交的数量（即买方主动以较高价买入） | 外盘大表示买方积极，看涨信号 |
| **振幅** | Amplitude | 当日最高价与最低价之差占昨收价的百分比 | 振幅 = (最高价 - 最低价) / 昨收价 × 100% |
| **市盈率** | PE Ratio (P/E) | 股价与每股收益的比值，衡量估值高低 | PE = 股价 / 每股收益 (EPS)。分为静态PE、动态PE、滚动PE(TTM) |
| **市净率** | PB Ratio (P/B) | 股价与每股净资产的比值 | PB = 股价 / 每股净资产。PB<1 称为"破净" |
| **股息率** | Dividend Yield | 每股股息与股价的比值 | 股息率 = 每股股息 / 股价 × 100% |
| **市销率** | PS Ratio (P/S) | 股价与每股营业收入的比值 | PS = 市值 / 营业收入 |
| **每股收益** | EPS | 公司净利润除以总股本 | EPS = 净利润 / 总股本 |

### 4.6 概念分类术语

| 术语 | 释义 | 典型特征 |
|---|---|---|
| **蓝筹股** | 业绩稳定、市值大、行业龙头地位的优质大盘股 | 如贵州茅台、工商银行、中国平安等 |
| **白马股** | 业绩透明、增长稳定、估值合理的价值型股票 | 财报亮眼、机构持仓比例高、走势平稳 |
| **题材股** | 因某一热点事件或政策而被炒作的股票 | 受消息面驱动，波动大，持续性不确定 |
| **妖股** | 走势异常、短期暴涨暴跌、脱离基本面的股票 | 连续涨停、换手率极高、散户追捧 |
| **龙头股** | 某一板块或题材中涨幅最大、最先启动、带动效应最强的股票 | 板块上涨时领涨、下跌时抗跌 |
| **黑马股** | 之前不被市场关注，但突然大幅上涨的股票 | 事前难以预判，事后分析往往有基本面或技术面支撑 |
| **僵尸股** | 长期成交低迷、股价几乎不动的股票 | 日成交额极低（可能不足百万）、无人关注 |
| **仙股** | 股价低于 1 元的股票（源自港股术语） | A 股中，连续 20 个交易日收盘价低于 1 元将触发退市 |
| **垃圾股** | 业绩差、财务状况恶劣的股票 | 常带有 ST/*ST 标记，退市风险高 |
| **成长股** | 业绩增速远高于市场平均水平的股票 | 营收/净利润年增长率 >30%，通常 PE 较高 |
| **周期股** | 业绩与经济周期高度相关的股票 | 如钢铁、煤炭、有色金属、房地产等 |

### 4.7 技术操作类术语

| 术语 | 释义 |
|---|---|
| **打板** | 在股价即将封涨停板时追入买入，赌涨停板封住不开（需要极强的执行力和判断力） |
| **炸板** | 股价封住涨停板后又被大量卖单砸开，涨停板被打开 |
| **跳空高开** | 当日开盘价高于昨日收盘价，K线图上形成向上的缺口 |
| **跳空低开** | 当日开盘价低于昨日收盘价，K线图上形成向下的缺口 |
| **缺口** | K线图上由于跳空高开或低开形成的价格空白区域。分为普通缺口、突破缺口、持续缺口、竭尽缺口 |
| **复权** | 对历史价格进行调整，消除因除权除息导致的价格跳变，使K线图连续可比 |
| **除权** | 上市公司送股、配股、转增股本后，股价按比例向下调整，总市值不变 |
| **除息** | 上市公司派发现金红利后，股价按每股分红金额向下调整 |
| **填权** | 除权除息后股价上涨，回到除权前的价格水平（甚至更高） |
| **贴权** | 除权除息后股价持续下跌，未能回到除权前的价格水平 |
| **翘板** | 在跌停板上用大量买单将股价从跌停价拉起 |
| **扫板** | 用大额资金一次性清扫涨停板上的卖单，快速封住涨停 |
| **排板** | 在涨停价位排队等待买入，因为卖单稀少需要等待 |
| **换手板** | 涨停过程中反复开板又封板，换手率极高的涨停 |

## 五、新手最容易混淆的术语对比

以下整理了 A 股市场中最容易被新手混淆的术语对，帮助你精准区分。

| 序号 | 术语A | 术语B | 核心区别 |
|---|---|---|---|
| 1 | **成交量 (VOL)** | **成交额** | 成交量 = 成交的**股数**（以"手"为单位），衡量交易活跃度；成交额 = 成交的**金额**（以"元"为单位），衡量实际资金参与量。高价股和低价股成交量相同时，成交额差异巨大，因此成交额更能反映真实的资金流动。 |
| 2 | **内盘** | **外盘** | 内盘 = 以**买入价**成交（卖方主动降价卖出），代表卖方力量；外盘 = 以**卖出价**成交（买方主动加价买入），代表买方力量。外盘 > 内盘通常为看涨信号，反之看跌。 |
| 3 | **除权** | **除息** | 除权因**送股/转增/配股**导致股本变化，股价按比例调低，但持有者股数增多；除息因**现金分红**导致公司现金减少，股价扣除每股分红金额调低，持有者获得现金。两者常同时发生（"除权除息日"）。 |
| 4 | **前复权** | **后复权** | 前复权 = 以**最新价格**为基准向前调整历史价格，图表显示的最新价就是真实价格，适合**看当前价位**和做技术分析；后复权 = 以**上市首日**价格为基准向后调整，适合**看真实累计涨幅**（如计算长期投资回报）。 |
| 5 | **反弹** | **反转** | 反弹 = 下跌趋势中的**短暂回升**，不改变下跌趋势，之后大概率继续下跌；反转 = 趋势发生**根本性转变**，如从下跌转为上涨。区别在于持续时间和力度，反转通常伴随基本面变化。 |
| 6 | **回调** | **反弹** | 回调 = **上涨趋势**中的短暂下跌，是多头的正常休整；反弹 = **下跌趋势**中的短暂上涨，是空头的暂时喘息。方向相反，但都不改变原有趋势。 |
| 7 | **集合竞价** | **连续竞价** | 集合竞价 = 在特定时间段**汇集所有订单**后一次性撮合，确定一个统一价格（开盘价/收盘价）；连续竞价 = 在交易时段内**逐笔实时**撮合，按"价格优先、时间优先"原则。 |
| 8 | **市盈率 (PE)** | **市净率 (PB)** | PE = 股价 / 每股收益，衡量公司**盈利能力**的估值倍数，适合利润稳定的公司；PB = 股价 / 每股净资产，衡量公司**资产价值**的估值倍数，适合资产密集型行业（如银行、地产）。 |
| 9 | **涨停** | **涨幅** | 涨停 = 股价达到当日允许的**最高涨幅上限**，触及涨停价；涨幅 = 当前价格相对昨收价的**实际上涨百分比**。涨停是涨幅的极端情况（如主板涨幅达到 +10% 即为涨停）。 |
| 10 | **建仓** | **补仓** | 建仓 = **首次**买入某只股票，从无到有建立头寸；补仓 = 在**已亏损**的情况下再次买入以摊低成本。建仓是主动选择，补仓往往是被动应对。 |
| 11 | **限价委托** | **市价委托** | 限价委托 = 指定一个价格，只有市场价达到该价格或更优时才成交，**保证价格但不保证成交**；市价委托 = 不指定价格，按当前市场最优价立即成交，**保证成交但不保证价格**。 |
| 12 | **牛市** | **熊市** | 牛市 = 市场整体持续上涨的行情，投资者信心高涨，赚钱效应显著；熊市 = 市场整体持续下跌的行情，投资者恐慌，亏钱效应显著。A 股历史上牛短熊长是突出特征。 |
| 13 | **ST** | **\*ST** | ST = Special Treatment（特别处理），因财务等异常被警示，涨跌幅限制 ±5%；*ST = 有**退市风险**警示，比 ST 更严重，可能面临退市。投资者应高度警惕 *ST 股票。 |
| 14 | **换手率** | **量比** | 换手率 = 当日成交量 / 流通股本，衡量**绝对**换手水平；量比 = 当日分钟均量 / 过去5日分钟均量，衡量当日成交量相对于**近期**的放大或缩小程度。换手率看"总量大不大"，量比看"今天比平时活跃不活跃"。 |

## 六、港股交易规则关键差异

对于同时关注 A 股和港股的投资者，了解两者的核心差异至关重要。

### 6.1 A 股 vs 港股核心规则对比

| 对比项 | A 股（沪深京） | 港股（联交所） |
|---|---|---|
| **交易制度** | **T+1**（当天买入次日才能卖出） | **T+0**（当天买入当天即可卖出，可日内多次交易） |
| **涨跌幅限制** | 有（主板±10%、创业板/科创板±20%、北交所±30%） | **无涨跌幅限制**（理论上一天可以涨跌任意幅度） |
| **交易时间** | 9:30-11:30 / 13:00-15:00 | 9:30-12:00 / 13:00-16:00（港股交易时间更长） |
| **最小交易单位** | **1 手 = 100 股**（所有股票统一） | **每手股数不统一**（不同股票每手可能是100、200、400、500、1000、2000股不等） |
| **资金交收** | T+1 | **T+2**（成交后第2个工作日完成交收） |
| **卖空机制** | 融券卖出（门槛高、券源少） | 卖空较为普遍和灵活 |
| **交易货币** | 人民币 (CNY) | 港币 (HKD) |
| **印花税** | 卖出时收取 0.05%（单边） | 买卖双方各收取 0.13%（双边） |
| **最小价格变动** | 0.01 元 | 根据股价不同有不同的最小变动价位（如 0.001、0.005、0.01、0.02 等） |

### 6.2 港股无涨跌停的风险提示

> ⚠️ **高度警惕**：港股没有涨跌停限制，极端情况下单日可以暴跌 90% 以上（"仙股闪崩"事件在港股市场并不罕见）。例如：
> - 某些小市值港股一天之内从几元跌至几分钱
> - 老千股（专门通过财务操作损害中小股东利益的股票）在港股中较为常见
>
> 因此，港股投资需要更强的风险意识和选股能力。

### 6.3 港股通（沪港通/深港通）

内地投资者可以通过**港股通**渠道投资港股，无需开设境外证券账户：

| 项目 | 说明 |
|---|---|
| 开通条件 | 证券账户资产不低于 **50 万元人民币**（连续 20 个交易日） |
| 交易标的 | 恒生综合大型股/中型股指数成分股，及同时在 A+H 上市的公司 |
| 交易货币 | 以**人民币**报价和结算（系统自动换汇） |
| 交易时间 | 跟随港股交易时间，但需在两地市场均为交易日时才可交易 |

## 七、实用提示：新手交易注意事项

### 7.1 开户与准备

1. **选择正规券商**：选择证监会批准的正规证券公司开户，优先考虑佣金费率（万 1~万 2.5）、交易软件体验和客户服务。
2. **模拟盘先行**：大多数券商提供模拟交易功能，新手应先用模拟盘熟悉交易流程，再投入真金白银。
3. **了解费用结构**：交易费用包括佣金（券商收取）、印花税（卖出时 0.05%）、过户费（0.001%）等。

### 7.2 交易纪律

1. **设定止损位**：每次买入前确定止损点（如亏损 5%-8% 无条件卖出），严格执行。T+1 制度下无法当天止损，更需提前规划。
2. **不追高、不杀跌**：避免在股价大涨后追入（"追涨"），也避免在股价大跌时恐慌卖出（"杀跌"）。
3. **控制仓位**：新手切忌满仓操作，建议单只股票仓位不超过总资金的 30%，总仓位控制在 50%-70%。
4. **分批买入/卖出**：不要一次性全部买入或卖出，可以分 2-3 次操作，降低择时风险。

### 7.3 信息与心态

1. **警惕小道消息**：不轻信各种"内幕消息"和"荐股群"，这些往往是骗局。
2. **关注官方信息**：以交易所公告、证监会官网、上市公司定期报告为准。
3. **保持平常心**：股市波动是常态，不因一时盈利而狂喜，也不因一时亏损而沮丧。长期学习和积累经验才是正道。
4. **用闲钱投资**：只用不影响生活的闲余资金投资，切勿借钱炒股或使用生活必需资金。

### 7.4 常见误区

| 误区 | 正确认知 |
|---|---|
| "涨停的股票明天一定继续涨" | 涨停后次日走势取决于多种因素，可能继续涨、横盘或回调，需综合分析 |
| "低价股更便宜，更值得买" | 股票的贵贱不看绝对价格，要看估值（PE、PB等），2 元的股票可能比 200 元的股票更"贵" |
| "成交量大就是好事" | 放量可能是主力出货（高位放量），也可能是资金进场（低位放量），需结合价格位置分析 |
| "跌了就补仓摊成本" | 盲目补仓可能越补越亏，补仓前需判断下跌原因和趋势是否已经企稳 |
| "别人赚钱了我也一定能" | 每个人的资金量、持仓时间、风险承受能力不同，不可盲目跟风 |

## 八、本章小结

本章系统介绍了 A 股市场的核心交易规则和常用术语：

### 关键知识点回顾

| 知识模块 | 核心要点 |
|---|---|
| **交易时间** | 9:15-9:25 集合竞价 → 9:30-11:30 上午连续竞价 → 13:00-14:57 下午连续竞价 → 14:57-15:00 尾盘集合竞价 |
| **涨跌停规则** | 主板 ±10%、创业板/科创板 ±20%（上市前5日无限制）、北交所 ±30%、ST ±5% |
| **T+1 制度** | 当天买入的股票次日才能卖出；卖出所得资金当天可用但次日才可取 |
| **仓位管理** | 建仓→加仓→减仓→清仓；新手建议半仓以下操作 |
| **港股差异** | T+0、无涨跌停、每手股数不统一、T+2 交收 |

### 学习建议

1. **反复熟读术语表**：术语是市场的"语言"，只有掌握了术语才能读懂分析文章和研报。
2. **结合实盘理解规则**：在模拟盘中亲自体验集合竞价、涨跌停、T+1 等规则的实际效果。
3. **先懂规则再学策略**：交易规则是基础中的基础，不懂规则就谈策略是空中楼阁。
