## 1. 2020年疫情行情：突发事件下的轮动路径

突发公共事件往往会瞬间改变市场资金的偏好，2020年的疫情行情是教科书级别的突发事件驱动型板块轮动。

### 🗓️ 轮动时间线
- **第一阶段（2020年1月-2月）：恐慌与医疗爆发**
  - **逻辑**：疫情爆发，防疫物资短缺。
  - **龙头股**：英科医疗（手套龙头，股价从15元起步，最终涨至最高近300元，涨幅近20倍）、道恩股份（口罩熔喷布原料）。
  - **特征**：鸡犬升天，只要沾边医疗防护、医药研发，均被资金疯狂炒作。

- **第二阶段（2020年3月-4月）：复工复产与基建/科技**
  - **逻辑**：国内疫情受控，政策开始发力稳增长，新老基建成为抓手。
  - **板块**：5G建设（中兴通讯）、特高压、水泥建材。

- **第三阶段（2020年下半年）：消费复苏与核心资产**
  - **逻辑**：经济全面复苏，资金追求业绩确定性。
  - **板块**：白酒（贵州茅台突破2000元，形成“喝酒吃药”行情）、免税概念（中国中免暴涨）。

### 💡 复盘启示
突发事件行情呈**“事件爆发（情绪炒作） → 政策对冲（基建发力） → 恢复常态（消费复苏）”**的传导路径。

## 2. 2020-2021年新能源/碳中和：政策与景气的共振

这是A股历史上持续时间最长、造富效应最强的趋势性板块行情之一。

### 🗓️ 行情演进路径
1. **产业爆发（2020下半年）**
   - **驱动**：新能源汽车渗透率拐点出现，光伏平价上网时代到来。
   - **核心龙头**：宁德时代（锂电）、比亚迪（整车）、隆基绿能（光伏硅片）、阳光电源（逆变器）。资金开始大规模抱团。

2. **政策加持，向上传导（2020年底-2021年初）**
   - **驱动**：2020年9月国家正式提出“碳达峰、碳中和”目标。
   - **资源端爆发**：上游锂矿成为最稀缺资源，赣锋锂业、天齐锂业、华友钴业等上演“有锂走遍天下”的暴涨行情。

3. **概念全面扩散（2021年3月-下半年）**
   - **驱动**：纯粹的“碳中和”主题炒作。
   - **扩散板块**：电力（风电、绿电）、环保设备、碳排放权交易概念（如长源电力、中钢国际等连板炒作）。

4. **见顶与泡沫破裂（2022年起）**
   - **结局**：机构抱团导致估值严重透支，叠加行业大幅扩产引发价格战（如碳酸锂价格雪崩），整个赛道迎来长达数年的估值杀跌。

### 💡 复盘启示
- **超级行情的公式**：`强力国家政策导向 + 行业利润真实爆发 = 超级赛道`。
- **警惕扩产周期**：高景气必然引来资本疯狂扩产，当供给过剩时，就是板块见顶之时。

## 3. 2023-2024年AI概念股行情：从概念到分化

ChatGPT的发布引爆了全球AI浪潮，A股的映射炒作特征极其明显。

### 🗓️ 炒作节奏
- **第一阶段（纯拔估值炒作）**：凡是涉及AI算法、数据、大模型的公司鸡犬升天。科大讯飞、昆仑万维、三六零等短期翻倍。
- **第二阶段（寻找“铲子股”即算力）**：市场意识到大模型还在烧钱，但卖算力服务器的是确定的赢家。浪潮信息、中科曙光、工业富联、中际旭创（光模块龙头）成为核心抱团标的。
- **第三阶段（业绩验证与分化）**：2024年报季，无法兑现利润的纯概念股暴跌，而中际旭创等光模块企业因北美订单爆发，业绩超预期，股价创出历史新高。

### 💡 复盘启示
科技题材炒作永远遵循：**“先炒朦胧概念 → 再炒基础设施（算力） → 最终看业绩兑现”**。不兑现业绩的公司，终将从哪里来回哪里去。

## 4. 国家队护盘行为与特征分析

“国家队”（汇金公司、证金公司、社保基金）是A股最强大的稳定器，其操作轨迹是判断市场大底的重要风向标。

### 🛡️ 角色定位与操作特征
- **汇金/证金（平准基金性质）**：
  - **手法转变**：2015年救市时倾向于直接买入大量个股；近年来，手法转变为**大举增持宽基ETF**（如沪深300、中证500、中证1000、中证2000 ETF），此举能高效平抑大盘波动，且不易造成个股操纵嫌疑。
  - **持仓偏好（压舱石）**：绝对重仓金融蓝筹（工农中建四大行、头部券商保险），因其高股息和极低估值能稳住大盘指数。
- **社保基金（战略配置型）**：
  - **参考配比**：常年维持约 40%金融 + 30%周期制造 + 20%科技 + 10%大消费 的均衡布局。
  - **特征**：偏好大市值、高ROE、基本面极其扎实的行业龙头。

### 🚨 护盘信号意义
当市场极度恐慌、流动性枯竭时，晚间公告“中央汇金买入ETF”或盘中相关ETF放出数百亿历史天量，往往是**政策底**的明确信号。

## 5. 北向资金（外资）操作特征解析

北向资金被称为“聪明钱”，是A股风格切换的重要推手。

### 🌐 资金属性分类
- **配置型外资（占比约75%）**：海外养老金、主权财富基金。换手率极低，注重长线投资中国经济基本面。
- **交易型外资（占比约25%）**：海外对冲基金、量化基金。快进快出，容易带来短期市场波动。

### 💼 核心持仓逻辑：“漂亮50”
北向资金极度偏好**高ROE（净资产收益率）、现金流充沛、具有品牌护城河**的各行业龙头。
- **最爱板块**：食品饮料（贵州茅台、五粮液）、医药生物（恒瑞医药）、家用电器（美的集团）、电子制造（立讯精密）。
- **信号意义**：北向资金持续数周大幅净流入，通常意味着外资对中国宏观经济预期向好，是大盘上涨的前奏。

## 6. 板块轮动规律与信号识别指南

### 🔄 经典板块轮动传导路径
一轮完整的主线行情，资金通常这样传导：
1. **龙头股先飞**：板块内逻辑最硬、业绩最好的一两只股票率先突破（如AI中的中际旭创）。
2. **跟风股补涨**：资金畏高，开始挖掘同板块内市值较小、尚未大涨的二三线股票。
3. **末端股炒作（垃圾股群魔乱舞）**：板块内连年亏损、仅有一点概念的边缘股票开始连板涨停。
4. **见顶退潮**：末端股炸板大跌，龙头股放量滞涨，主线行情宣告结束。

### 📋 板块启动的先行信号清单
- [ ] **政策催化**：高层会议或部委出台重磅产业支持政策。
- [ ] **龙头异动**：板块总龙头突然放量大涨甚至涨停。
- [ ] **板块效应**：同板块内当天出现3只以上涨停板。
- [ ] **大单资金**：Level-2数据显示主力资金连续数日净流入该板块。
- [ ] **研报密集发布**：各大券商突然集体发布该行业的看多研报。

### 📉 板块退潮的信号清单
- [ ] **高位巨震**：龙头股在高位出现长上影线或巨量阴线。
- [ ] **利好不涨**：媒体疯狂报道该行业的利好，但股价却高开低走。
- [ ] **补涨龙陨落**：后排跟风股出现“天地板”（涨停直接砸到跌停）。

> **💡 散户生存法则**：
> 宁可买在轮动行情的**起跑线**或**半山腰**，绝不去接最后一棒的边缘垃圾股。如果错过了龙头，耐心等待下一次主线切换，不要在退潮期去“抄底”已经被资金抛弃的板块。
