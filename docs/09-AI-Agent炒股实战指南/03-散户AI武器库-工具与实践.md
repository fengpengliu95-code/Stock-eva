## 2. 使用大模型（Claude/GPT）的通用分析Prompt

如果你不会写代码，直接使用大语言模型的对话框，也能成为强大的辅助工具。以下是直接可复制的 Prompt 工程模板。

### 📊 研报浓缩提炼 Prompt
*(作用：当你面对一份50页的券商研报，看不懂或没耐心看时)*
```text
请你作为资深基金经理，帮我精读以下研报内容。
要求：
1. 忽略所有套话和免责声明。
2. 直接告诉我核心逻辑：这篇研报认为这家公司未来业绩增长的最大驱动力是什么？
3. 提取所有关于未来3年营收和净利润的预测数据，整理成一个表格。
4. 找出研报中提到的“风险提示”部分，并按照致命程度进行降序排列。
[在此粘贴研报文本]
```

### 📰 异动复盘诊断 Prompt
*(作用：盘后某只股票意外大跌，让你快速搞清状况)*
```text
今天A股股票【股票名称，如：贵州茅台】出现了异常下跌。
请结合今天的宏观新闻、行业动态以及资金面表现，帮我分析：
1. 下跌的最直接诱因是什么？（政策利空、业绩不及预期、还是大盘恐慌？）
2. 这种下跌是情绪化的短期错杀，还是基本面逻辑发生了根本性恶化？
3. 对比历史相似跌幅，这只股票通常需要多久能企稳？
请保持客观中立，以事实数据为基础进行推理。
```

## 3. 开源项目推荐：站在巨人的肩膀上

不要从零造轮子，去 GitHub Fork 这些成熟的开源项目，稍微修改就能用。

### 🔥 明星项目：daily_stock_analysis (38K+ Stars)
- **项目亮点**：零服务器成本！完全利用 GitHub Actions 的免费算力，每天自动运行。
- **功能**：每日收盘后，自动获取市场龙虎榜、北向资金数据，抓取财经新闻，调用大模型生成《每日A股复盘简报》，然后自动推送到你的微信（通过 Server酱 或 WxPusher）、Telegram 或邮件。
- **如何上手**：
  1. 注册 GitHub 账号，Fork 该仓库。
  2. 在仓库的 `Settings -> Secrets` 中，配置你的大模型 API Key（如 OpenAI Key 或国内的 DeepSeek Key，后者极便宜）。
  3. 启用 Actions，它每天下午就会自动把复盘报告发到你手机上。

### 🧠 进阶项目：TradingAgents-CN
- **项目亮点**：实现了多智能体（Multi-Agent）协作。它把分析任务拆解给“宏观Agent”、“技术Agent”、“基本面Agent”，然后汇总辩论。
- **适用人群**：懂一点 Python 开发，想要构建复杂的研报生成系统的极客。

## 4. 避坑指南：AI炒股的四大风险提示

在你充满热情地把 API 接入交易系统前，请务必冷却一下头脑：

1. **AI 幻觉（最致命）**：大模型有“一本正经胡说八道”的毛病。它可能由于搞错了单位（把万元看成亿元），得出公司利润暴增100倍的结论。**应对策**略：财报核心数据必须用 Python 程序进行计算，不能交由 LLM 推理；LLM 只负责文字解释和语义理解。
2. **回测陷阱（前视偏差）**：在平台上跑回测，年化收益率动辄 50%。这通常是因为你使用了“未来数据”（比如在今天用明天的收盘价计算指标）。**应对策略**：扣除 0.3% 的摩擦成本，回测结果打个 3 折，才是你实盘可能达到的真实收益。
3. **API 成本控制**：如果是循环分析5000只股票的每一条新闻，大模型的 API 账单会瞬间爆炸。**应对策略**：先用传统代码指标（如过滤掉市值小于50亿、跌破20日线的票）把5000只股票筛选到50只，再交给大模型去消耗 Token 进行深度分析。
4. **数据合规与封禁**：频繁高并发地爬取免费财经网站（如使用AkShare），会导致你的 IP 被封锁。**应对策略**：在代码中加入随机休眠（`time.sleep()`），善待免费数据源。

> **终极忠告**：
> 最好的AI炒股实战，不是让AI替你赚钱，而是让AI帮你**节省每天3小时的盯盘和搜集信息的时间**。把节省下来的时间用来思考大局，陪伴家人，才是技术的真正价值。
