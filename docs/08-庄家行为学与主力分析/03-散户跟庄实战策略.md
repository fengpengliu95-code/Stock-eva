## 1. 识别庄家入场的十大核心信号

当你发现一只股票同时满足以下3个以上信号时，它大概率已经被主力资金盯上并完成了建仓：

1. **红肥绿瘦（最经典）**：底部的上涨日明显放量（红色量柱高），下跌日极度缩量（绿色量柱矮）。
2. **缩量抗跌**：大盘暴跌，它却横盘不动，成交量萎缩到极致（说明筹码已被锁定）。
3. **底部放量滞涨**：在长期底部突然连续放出巨量，但股价就是涨不上去（庄家在压盘吃货）。
4. **单峰密集**：筹码分布图显示，所有筹码高度集中在底部一个狭窄的价格区间内。
5. **股东人数锐减**：季度财报显示，前十大流通股东新进多家机构，且总体股东人数环比大幅减少（筹码从散户向庄家集中）。
6. **利空不跌反涨**：公司出利空消息，股价低开后迅速被大资金买起收阳线。
7. **异常的大单**：盘口经常出现几千手的大单压在卖盘，但股价却不跌，下方总有隐形买盘接单。
8. **走势独立**：大盘跌它涨，大盘涨它横盘，完全走出独立行情。
9. **均线由乱转顺**：长期纠缠不清的均线（5、10、20、60日），在底部开始逐渐靠拢，并隐隐呈现多头排列。
10. **龙虎榜异动**：底部首次放量涨停，龙虎榜上出现知名游资或机构席位大举买入。

## 2. 龙虎榜数据分析实战指南

龙虎榜是交易所每天盘后公布的异动股成交明细，是散户偷看主力底牌的最佳窗口。

### 🔍 席位辨识
- **“机构专用”**：代表公募、私募、险资等正规军。风格稳健，如果龙虎榜买方前五有3家以上是“机构专用”，说明该股获得了主流资金认可，**后市持续性强**。
- **营业部席位**：代表游资和个人大户。风格激进，如“东方财富拉萨团结路”（被称为散户集中营，多为接盘侠）、“国泰君安上海江苏路”等。

### 📊 榜单实战解读
- **看买卖净额（最重要）**：买一到买五的总金额，如果远大于卖一到卖五的总金额（买卖净额为大额正数），说明主力净流入，次日溢价概率高。
- **看集中度**：如果“买一”买入1个亿，而“买二”只有1000万（一家独大），这是危险信号。游资霸盘，次日极易砸盘跑路。最健康的榜单是买一到买五金额均匀，这叫**“市场合力”**。
- **看机构博弈**：如果买方全是游资，卖方全是“机构专用”，说明机构在高位出货，游资在接盘，这通常是**行情见顶**的信号，坚决不碰。

## 3. 大单资金与筹码分布的实战应用

### 💰 主力资金流向（Level-2 数据）
软件上的“主力资金净流入”具有欺骗性，主力常通过“对倒”制造假象。
- **实战看点**：不要看单日的流入流出，要看**连续3-5天的资金趋势**。如果股价在缓慢上涨，且主力大单资金连续5天净流入，这是真金白银的建仓。
- **量价背离警报**：如果股价每天都在涨，但软件显示主力大单资金每天都在净流出，说明主力在**边拉边撤**，随时会闪崩。

### ⛰️ 筹码分布图（移动成本分布）
- **低位单峰密集（金矿）**：股价长期下跌后，上方高位筹码全部消失，集中到下方形成一个尖锐的山峰。**实战：当股价放量突破该单峰的最高点时，是绝佳买点。**
- **高位单峰密集（地雷）**：股价大幅上涨后，底部的筹码山峰消失，转移到了高位。说明主力已经把底部的获利筹码派发给了高位接盘的散户。**实战：必须果断清仓离场。**
- **双峰填谷（波段）**：股价上下各有一个筹码峰。**实战：在下峰支撑位买入，在上峰阻力位卖出，做波段。**

## 4. 散户必须避开的致命陷阱

1. **涨停板诱多陷阱**：早盘迅速拉高至+8%以上甚至触及涨停，然后全天缓慢阴跌，这是最典型的拉高出货。
2. **尾盘偷袭陷阱**：全天死水一潭，在下午2:50分后突然用少量资金拉高股价。这通常是非主力资金为了做漂亮日K线图形的把戏，次日必定低开。
3. **假破位陷阱（主力的温柔一刀）**：股价在一个重要支撑位（如箱体下沿或60日均线）突然放量跌破，散户绝望割肉；结果次日或第三天，一根大阳线直接拉回原位，随后开启主升浪。**破解之道：破位时减仓，一旦大阳线收回破位点，立即加仓买回！**
4. **利好出尽陷阱**：当一只股票因为某个利好预期（如业绩预增）已经上涨了50%，当这则利好正式在公告里发布时，就是主力砸盘出货的最佳时机（Buy the rumor, sell the news）。

## 5. 📋 实操检查清单与交易决策框架

在点击“买入”或“卖出”按钮前，请强迫自己对照以下清单：

### 🟢 【买入前自检清单】（必须满足至少4项才可买入）
- [ ] 1. 股票处于均线多头排列（20日均线向上）。
- [ ] 2. 筹码分布显示底部筹码没有严重松动。
- [ ] 3. 属于当前市场的热门主线或政策支持板块。
- [ ] 4. 不是因为看到了利好新闻才冲动买入。
- [ ] 5. 我已经明确了止损价（例如买入价下跌7%或跌破20日均线）。
- [ ] 6. 本次买入资金不超过我总仓位的30%。

### 🔴 【持仓监控与卖出触发条件】（满足任意1项必须卖出）
- [ ] 1. **纪律红线**：股价跌破我设定的止损价，无条件清仓，不找任何理由。
- [ ] 2. **趋势破位**：高位放量跌破10日或20日关键均线。
- [ ] 3. **见顶信号**：高位出现极长的上影线，且伴随历史天量成交。
- [ ] 4. **逻辑兑现**：当初买入的利好预期已经正式发布。
- [ ] 5. **主力撤退**：筹码底峰彻底消失，全部转移至高位。
