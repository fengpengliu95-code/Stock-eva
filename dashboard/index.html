📐 关键公式速查

量化交易必备公式一览，点击卡片查看详细说明

估值指标
市盈率 (PE)
PE = 股价 / 每股收益(EPS)
衡量投资者为每单位盈利支付的价格，PE越低可能越便宜，但需结合行业平均与增长率判断。
估值指标
市净率 (PB)
PB = 股价 / 每股净资产
衡量股价相对于账面价值的溢价程度。PB < 1 可能表示股价低于清算价值。
盈利能力
净资产收益率 (ROE)
ROE = 净利润 / 股东权益
巴菲特最看重的指标之一，反映公司用股东资本创造利润的效率。ROE > 15% 通常被视为优秀。
风险评估
夏普比率 (Sharpe Ratio)
Sharpe = (Rp - Rf) / σp
衡量每承受一单位风险所获得的超额回报。Sharpe > 1 为良好，> 2 为优秀。Rp=组合收益率, Rf=无风险利率, σp=收益标准差。
仓位管理
凯利公式 (Kelly Criterion)
f* = (b·p - q) / b
确定最优投注比例。b=赔率, p=获胜概率, q=失败概率(1-p)。实战中常用半凯利(f*/2)以降低风险。
技术指标
相对强弱指数 (RSI)
RSI = 100 - 100 / (1 + RS)
RS = 平均上涨幅度 / 平均下跌幅度。RSI > 70 为超买（可能回调），RSI < 30 为超卖（可能反弹）。
技术指标
MACD
MACD = EMA(12) - EMA(26)
信号线 = MACD的9日EMA。MACD上穿信号线为金叉（买入信号），下穿为死叉（卖出信号）。
